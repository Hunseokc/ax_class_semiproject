# 01. 프로젝트 기획서

## 1. 프로젝트명
**StockMind** — 국내·미국 주식 데이터 백엔드와 주식 분석 대시보드

## 2. 배경
- 개인 투자자는 국내(KRX)와 미국(NASDAQ) 종목을 함께 보지만, 시세·지수·환율·재무·공시가 서로 다른 사이트와 통화, 회계기준에 흩어져 있다.
- 종목 하나를 판단하려면 같은 업종의 경쟁 종목과 비교해야 하는데, 국내·해외 종목을 한 화면에서 같은 기준(원화 환산, 기간 수익률 등)으로 비교하기 어렵다.
- "이 시드로 이 종목들을 담으면 얼마가 남고, 환율이 바뀌면 손익이 어떻게 되는가"를 계산하려면 지금은 엑셀로 직접 계산해야 한다.

## 3. 문제 정의
| # | 문제 | 해결 방향 |
|---|---|---|
| P1 | 출처마다 형식·통화·시간대가 다른 원천 데이터 | 수집·전처리 후 PostgreSQL 정규화 스키마로 통합 (시장 단위 속성 분리) |
| P2 | 수익률·변동성·MDD 같은 파생 지표를 매번 수작업으로 계산 | SQL VIEW(`v_stock_metrics`)로 일관되게 계산 |
| P3 | 국내·해외 경쟁 종목 비교가 어려움 | 경쟁 그룹(N:M) + 윈도우 함수(RANK, AVG OVER) 비교, 기준일=100 환산 차트 |
| P4 | 시드 기반 모의 배분 계산의 번거로움 | 담은 시점 가격·환율을 고정 저장하는 장바구니형 모의 포트폴리오 |
| P5 | 외부 API 호출 비용·차단 위험 | TTL 기반 갱신 정책(주가·지수·환율 1시간, 그 밖 4시간), advisory lock으로 중복 호출 방지, 데이터 종류별 유효기간 |

## 4. 목적
1. 원천 데이터를 **재현 가능한 적재 파이프라인**으로 PostgreSQL에 구조화한다.
2. 정규화·제약조건·인덱스·VIEW를 갖춘 DB 설계와 분석 SQL(JOIN, GROUP BY, HAVING, 윈도우 함수, CTE)을 구현한다.
3. FastAPI로 조회·분석·CRUD API를 제공하고, 바닐라 HTML/CSS/JS 대시보드로 시각화한다.

## 5. 대상 사용자
- 국내·미국 주식을 함께 관심 있게 보는 개인 투자 입문자
- 경쟁 종목 간 지표를 빠르게 비교하고 싶은 사용자
- 실제 매매 전에 시드 배분을 시험해 보려는 사용자
- 1차는 **로그인 없이** 사용한다. 로컬은 단일 사용자(데모) 모드로 모든 요청을 설정값 `DEFAULT_USER_ID`(기본 1 = demo) 사용자로 처리하고, 배포(`GUEST_SESSION_ENABLED=true`)에서는 브라우저마다 서명된 세션 쿠키로 **게스트 사용자**를 나눈다: 쿠키가 없을 때 조회는 demo 화면을 보여 주고, 첫 쓰기 요청(관심종목 추가 등)에서 demo의 관심종목·포트폴리오를 복사한 게스트를 만들어 쿠키에 담는다(쿠키를 지우거나 다른 브라우저면 새 게스트). 어느 쪽이든 포트폴리오·관심종목은 소유자만 접근하도록 확인한다(남의 리소스는 404). 로그인은 2차(2026-10-26 배포)에 요청 사용자를 정하는 `get_current_user_id()`가 JWT access token을 먼저 보도록 바꿔 도입했다(이메일·Google, 가입하면 게스트 관심종목을 이어 씀, 게스트 포트폴리오 저장은 로그인 후)

## 6. 주요 기능
| 화면 | 기능 |
|---|---|
| 대시보드 홈 | 주요 지수·원자재 선물·USD/KRW 카드(고르기 상자, 스파크라인 1개월·3개월·1년, 52주 위치, 휴장 배지, 한 줄 시장 요약), 관심종목(리스트·카드), 섹터 히트맵, 시장 심리 지수(간이 계산), 내 포트폴리오(비중 도넛·범례), 시장 주목 종목 TOP 5(거래량 급증·매력도 × 국내·미국 카드 4장) |
| 주식 리스트 | 시장 탭, 거래량/시가총액 순위(노출 종목 + 비교군 636개 — 테마 38개 × 국가별 시가총액 상위 10, 25개씩 페이지), 검색·테마·업종 섹터 필터, ★ 관심 토글, 포트폴리오 담기 |
| 종목 상세 | 가격 차트, 핵심 지표, 주 테마·보조 테마 배지, 매력도(프리셋별 점수·팩터 기여도·지표 원값/Z·국가 내 순위 — 금융은 금융끼리), 원자재 연동 업종의 연결 원자재 가격 위치, 수치 분석, FY 재무 추이, 경쟁 종목 비교, 최근 공시 |
| 모의 포트폴리오 | 시드 설정, 수량/금액/비중 모드로 담기, 시드 초과 방어, 요약(환 효과 분리)·비중 차트 |
| 설정 | 화면 테마(라이트 기본 / 다크) — 브라우저에 저장, 로그인하면 계정에도 저장. 계정(비밀번호 변경·모든 기기 로그아웃·탈퇴) |
| 로그인 (2차) | 이메일·비밀번호 / Google 로그인(JWT access 15분 + refresh 14일 httpOnly 쿠키, Redis). 가입하면 게스트로 담은 관심종목을 이어 쓰고, 포트폴리오 저장은 로그인 후 |
| 공통 | 일봉 기준·마지막 갱신 시각 표시, TTL 기반 새로고침 |

## 8. 기대 효과
- 흩어진 데이터를 하나의 정규화된 DB로 통합하는 데이터 백엔드 설계·구현 경험
- 파생 지표·상대 평가를 SQL로 계산해 재현성과 검증 가능성 확보(손계산 테스트)
- 확장 기반: Provider 인터페이스, `users` 테이블, 요청 사용자 의존성 `get_current_user_id()`(2차에서 JWT 검증으로 교체), JSON 구조의 분석 결과 → 2차(로그인·React), 3차(LLM 보고서) 확장 용이
