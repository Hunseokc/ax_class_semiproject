# 04. 도메인 모델 정의서

## 1. 도메인 서술
> 시장에 여러 **종목**이 상장되어 있고, 종목마다 **일별 시세**·**밸류에이션**·**재무제표**·**공시**가 쌓인다. 종목은 **경쟁 그룹**에 속하며 서로 비교된다. **사용자**는 **관심종목**을 표시하고, **시드**를 가진 **포트폴리오**에 종목을 **담아** 계산한다. **지수**와 **환율**은 시장 전체의 배경 정보다.

## 2. 명사 추출 → 후보 분류
| 명사 | 분류 | 판단 근거 |
|---|---|---|
| 시장 | **Entity** (Market) | 통화·국가·시간대를 가진 독립 개념, 여러 종목이 공유 |
| 종목 | **Entity** (Stock) | 핵심 식별 대상 |
| 경쟁 그룹 | **Entity** (PeerGroup) | 이름·설명을 가진 독립 개념 |
| 그룹 소속 | **관계 + 속성** (Stock N─M PeerGroup) | 교차 테이블, 주 그룹 여부(is_primary) 속성 |
| 일별 시세 | **Entity** (DailyPrice) | 종목×날짜마다 생기는 사실 |
| 밸류에이션 | **Entity** (ValuationSnapshot) | 종목×기준일 사실 (외부 제공값) |
| 재무제표 | **Entity** (FinancialStatement) | 종목×결산기 사실 |
| 공시 | **Entity** (Disclosure) | 고유 접수번호를 가진 문서 |
| 지수 | **Entity** (Index) | 시장 배경 정보 |
| 지수 일별 값 | **Entity** (IndexDailyPrice) | 지수×날짜 사실 |
| 환율 | **Entity** (FxRate) | 시각별 USD/KRW |
| 사용자 | **Entity** (User) | 관심종목·포트폴리오 소유자 |
| 관심종목 | **관계 + 속성** (WatchlistItem) | User N─M Stock, 정렬순·추가 시각·메모·목표가(종목 통화)·수정 시각 속성 보유. 목표가 대비 괴리율은 현재가에서 계산하는 값이라 저장하지 않음 |
| 포트폴리오 | **Entity** (Portfolio) | 시드를 가진 장바구니 |
| 담은 종목 | **Entity** (PortfolioItem) | 수량·기준가·기준 환율을 가진 항목 |
| 매력도 프리셋 | **Entity** (ScoringPreset) | 이름·설명과 팩터별 가중치를 가진 설정 |
| 프리셋 가중치 | **Entity** (ScoringWeight) | 프리셋×팩터마다 하나의 가중치 |
| 매력도 지표 값 | **Entity** (StockMetricValue) | 종목×기준일×지표의 원값·Z, 재생성 가능한 파생 결과 |
| 매력도 점수 | **Entity** (StockScore) | 종목×기준일×프리셋의 재생성 가능한 파생 결과 |
| 주 그룹 | 속성 (그룹 소속.is_primary) | 섹터 중립화 기준, 종목당 최대 1개 |
| 적재 작업 | **Entity** (IngestionLog) | 운영 기록, 갱신 TTL 판단 근거 |
| 시드 | 속성 (Portfolio.seed_krw) | |
| 수익률·변동성·MDD·이동평균 | **파생값** → VIEW | 시세에서 언제든 계산 가능, 저장 안 함 |
| 원가 | 파생값 → 생성 컬럼 (PortfolioItem.cost_krw) | 같은 행 값만으로 계산 |
| 평가금액·손익 | 파생값 → 서비스 계산 | 최신 시세·환율 의존 |

## 3. Entity와 속성
| Entity | 식별자 | 주요 속성 | 비고 |
|---|---|---|---|
| Market | market_id (자연키 code) | code, country, currency, timezone | |
| Stock | stock_id (자연키 market+ticker) | ticker, name, name_en, corp_code, cik, is_active | |
| PeerGroup | group_id (자연키 name) | name, description | |
| DailyPrice | (stock, trade_date) | open, high, low, close(수정주가), volume | |
| ValuationSnapshot | (stock, as_of) | per, pbr, eps, bps, market_cap, shares_outstanding, source | |
| FinancialStatement | fin_id (자연키 stock+period_end+period_type) | revenue, operating_income, net_income, total_assets, total_equity, total_debt, data_source, accounting_std | |
| Disclosure | disclosure_id (자연키 rcept_no) | title, report_type, filed_at, url, data_source | |
| Index | index_id (자연키 code) | name, source_symbol, display_order | |
| IndexDailyPrice | (index, trade_date) | open, high, low, close | |
| FxRate | fx_id (자연키 granularity+rate_at) | rate_at, usd_krw, granularity, source | |
| User | user_id (자연키 nickname) | nickname, created_at | 인증 없음 |
| WatchlistItem | (user, stock) | sort_order, added_at | |
| Portfolio | portfolio_id (자연키 user+name) | name, seed_krw, created_at, updated_at | |
| PortfolioItem | item_id (자연키 portfolio+stock) | quantity, ref_price, ref_fx_rate, ref_date, memo, cost_krw | 체결 기록 아님 |
| ScoringPreset | preset_id (자연키 code) | code, name, description | |
| ScoringWeight | (preset, factor) | weight | 프리셋별 합 = 1 |
| StockMetricValue | (stock, as_of, metric) | factor, raw_value, z_raw, z_adj | 파생 |
| StockScore | (stock, as_of, preset) | 팩터 점수 5종, composite, score, factor_coverage, data_quality | 파생 |
| IngestionLog | log_id | source, job_type, stock, status, rows_loaded, error, started_at, finished_at | |

## 4. 관계
| 관계 | 카디널리티 | 참여 | 구현 | 삭제 정책 |
|---|---|---|---|---|
| Market — Stock | 1 : N | Stock 필수 | stocks.market_id FK | 제한(기본) |
| Stock — PeerGroup | N : M | 선택 | peer_group_members | 양쪽 CASCADE |
| Stock — DailyPrice | 1 : N | DailyPrice 필수 | PK에 stock_id 포함 | CASCADE |
| Stock — ValuationSnapshot | 1 : N | | PK에 stock_id 포함 | CASCADE |
| Stock — FinancialStatement | 1 : N | | FK | CASCADE |
| Stock — Disclosure | 1 : N | | FK | CASCADE |
| Stock — StockMetricValue | 1 : N | | PK에 stock_id 포함 | CASCADE |
| Stock — StockScore | 1 : N | | PK에 stock_id 포함 | CASCADE |
| ScoringPreset — ScoringWeight | 1 : N | | PK에 preset_id 포함 | CASCADE |
| ScoringPreset — StockScore | 1 : N | | PK에 preset_id 포함 | 제한(점수가 있는 프리셋은 삭제 불가) |
| Market — Index | 1 : N | Index 선택(0..1) | indices.market_id NULL 허용 | 제한 |
| Index — IndexDailyPrice | 1 : N | | PK에 index_id 포함 | CASCADE |
| User — Stock (관심종목) | N : M | 선택 | watchlist_items | 양쪽 CASCADE |
| User — Portfolio | 1 : N | | FK | CASCADE |
| Portfolio — PortfolioItem | 1 : N | | FK | CASCADE |
| Stock — PortfolioItem | 1 : N | | FK | **RESTRICT** (담긴 종목은 삭제 불가 → 원가 근거 보존) |
| Stock — IngestionLog | 1 : N | 선택 | FK NULL 허용 | SET NULL (로그는 남김) |

FxRate는 다른 Entity와 FK 관계가 없다. 통화 환산이 필요한 곳(시총 원화 환산, 담기 기준 환율)에서 조회 시점에 참조하며, 담은 시점 환율은 PortfolioItem에 복사해 둔다(05 문서의 의도적 비정규화 1).

## 5. 도메인 규칙
| 규칙 | 보장 위치 |
|---|---|
| 같은 시장에 같은 티커는 하나 | UNIQUE (market_id, ticker) |
| 고가 ≥ 저가, 가격 > 0, 거래량 ≥ 0 | CHECK |
| 시드 > 0, 수량 > 0, 기준가·환율 > 0 | CHECK |
| 한 포트폴리오에 같은 종목은 한 번 | UNIQUE (portfolio_id, stock_id) |
| 원가 = 수량 × 기준가 × 기준 환율 | 생성 컬럼 cost_krw |
| **원가 합계 ≤ 시드** | 행 간 제약 → 서비스 계층 트랜잭션 + `SELECT … FOR UPDATE` |
| 매력도 점수 0~100, 유효 팩터 수 0~5, 가중치 0~1 | CHECK |
| 종목당 주 그룹 최대 1개 | 부분 UNIQUE 인덱스 (stock_id) WHERE is_primary |
| **프리셋별 가중치 합 = 1** | 행 간 제약 → 적재 시 검증(`validate_presets`) + 테스트 |
| 담은 종목은 원가 근거를 위해 삭제 불가 | FK ON DELETE RESTRICT |
