# 매력도 모델 v3 계획 (2026-10-27)

> 장부 D-024~D-035를 실행 단위로 풀어 쓴 문서다. 결정의 이유는 장부, 지표별 근거는 `근거_정렬표.md`에 있다.

## 1. 방향 (세 줄)

1. **점수가 거짓말하지 않게** — 분류·통화·음수 자본·금융 구조처럼 입력이 틀린 곳을 먼저 고친다.
2. **근거를 적는다** — 지표마다 참고 연구의 정의와 차이를 기록하고, 근거가 약한 것(지금의 성장성)은 이름과 설명을 낮춘 뒤 근거 있는 후보로 바꾼다.
3. **조정에 쓰지 않은 데이터로 닫는다** — 기준을 같은 데이터로 바꾸지 않고, 다른 날짜와 미리 봉인한 반례로 종료를 판정한다.

## 5. 측정 라운드 M1 (읽기 전용)

비교는 **기준 스냅샷 S1·S2**(D-041)에서 하고, 두 날짜 모두 같은 결론일 때만 채택안으로 낸다. 독립 기준(R10 정의)·required·표시 모순을 쓴다. 합격선은 바꾸지 않는다.

| 대상 | 후보 | 비교 기준선 |
|---|---|---|
| 과거 실적 성장 1층 | 매출 CAGR 3년·5년 / 성장 꾸준함(5년 중 증가 연수, 성장률 표준편차) / 매출 CAGR − 총자산 CAGR | 지금 2년 매출 CAGR |
| 과거 실적 성장 2층 | 5년 영업이익/총자산 변화 | 지금 2년 영업이익 변화 ÷ 2년 전 총자산 |
| 최근 실적 흐름 3층 | 분기 SUE(영업이익·매출 동일 가중, 표준편차 하한, 제출일 기준 유효, 금융 제외) | 3층 없음 |
| 저평가 분모 | EV(시총 + 순차입금) | 시총(D-001) |
| 결산 시점 | TTM | FY(D-008) |
| 일회성 차단 | min(순이익, 0.78 × 영업이익 + 지분법이익) | 지금 규칙(D-029) |
| 수익성 | 매출총이익/총자산(Novy-Marx) | 영업이익/총자산 |
| 독립 기준선 | F-Score 9개, G-Score — 모델 점수와의 상관·상위 겹침만 기록 | — |

원칙: 신호는 같은 무게, 데이터로 가중치를 맞추지 않는다. 후보마다 근거 등급(정렬표)을 함께 적는다.

```
국내·미국 상장사 중에서, 아래 투자 성향 각각에 대해 "상식적으로 상위권이면 이상한 종목"과
"상식적으로 하위권이면 이상한 종목"을 합쳐 20~30개 골라 YAML 로 써라.

항목마다 market, ticker, 성향, 기대 방향(top20 안이면 이상 / bottom 절반이면 이상), 이유 한 줄.
```
