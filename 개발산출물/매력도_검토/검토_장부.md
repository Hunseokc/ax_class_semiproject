# 매력도 모델 검토 장부

> 매 검토 라운드의 입력이자 출력이다. 라운드 검토자는 **열린 이슈에만 추가**할 수 있고, 결정 기록은 모델 담당자만 쓴다.
> 기준 문서는 `개발산출물/09_매력도_점수_정의서.md` 하나뿐이다. 모델이 바뀌면 09를 먼저 고치고, 여기 라운드 기록에 09의 커밋 SHA를 남긴다.
> 결정 D-001~D-013은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-27, 근거: 10·11번 보고서). 검토자와 다른 세션이 결정했으므로 검토 분리는 유지된다.

## 0. 종료 조건

아래를 모두 만족하면 검토를 멈춘다.

1. **관점이 서로 다른 2라운드 연속**으로 새 치명·높음 이슈가 0개
2. `sanity_cases.yaml`의 `required` 케이스 전부 통과 (`known_fail`은 결정 번호가 있으면 통과로 본다)
3. 열린 이슈 중 치명·높음이 0개 (남은 중간·낮음은 결정 기록으로 옮기거나 다음 버전으로 미룸)

> 종료는 "논리적 흠이 최소화됐다"는 뜻이지 "수익률이 좋다"는 뜻이 아니다. 수익률 검증은 점수 이력이 쌓인 뒤 따로 한다(D-013).

## 3. 결정 기록

알고 받아들인 흠과 설계 선택. **라운드 검토자는 새 증거(이전에 없던 수치·반례)가 있을 때만 다시 열 수 있다.** 다시 열 때는 그 새 증거를 반드시 적는다.

### D-001 EV 수집 전까지 저평가 분모는 시가총액
- 날짜 / 관련 이슈: 2026-10-27 / P8, R1-1 잔여
- 결정: 순차입금·영업권을 수집하기 전까지 저평가 분모는 시가총액, B/P는 장부가 그대로 쓴다. 수집은 D-011의 PR 7로 한다.
- 이유: DB에 순차입금·영업권 필드가 없다. 세후 보수 이익(D-002)으로 부채 효과를 일부 줄였지만 시총 분모로는 완전히 고칠 수 없다(11번 2절 P8).
- 감수하는 것: T 가치 1위, VZ 가치 2위·균형 9위, 사업형 지주(한일홀딩스 가치 16위, 한국앤컴퍼니 균형 7위)가 다소 싸 보인다. 합병 장부가가 큰 종목(SIRI)의 B/P 과대.
- 다시 열 조건: 순차입금 또는 비지배지분 순이익 수집 완료 시.

### D-002 모델 본체는 11번 R11안을 채택한다
- 날짜 / 관련 이슈: 2026-10-27 / P1·P2·P5·P6·P7·P12·P13, R1-1~R1-4
- 결정: 11번 보고서 4절 R11 뼈대를 그대로 모델 v2로 한다.
  - 저평가: ① 세후 보수 이익/시총 — 해마다 e = min(지배주주 순이익, 0.78 × 영업이익), 그다음 min(최신 e, 3년 평균 e). 순이익이 없으면 0.78 × 영업이익 ② B/P ③ 가치 함정 신호 — 2년 비교 5개(영업흑자·영업이익↑·매출↑·영업이익률↑·부채/자산↓, 이익 관련 2개는 2년 전 흑자일 때만) 중 '예' 비율의 로버스트 Z를 **0 이하로 잘라 감점만**
  - 수익성: 영업이익/총자산, 영업이익률
  - 성장성: 2년 매출 CAGR, 2년 영업이익 변화 ÷ 2년 전 총자산(**2년 전 영업흑자일 때만**, 아니면 비움)
  - 안정성: (2 × 변동성 + 1 × 부채/자산) / 3. 1년 최대 낙폭은 뺀다
  - 주가 흐름: 12-1개월 수익률(그대로)
  - 금융 묶음: 11번 4절 금융 행 그대로
  - 합산: 로버스트 Z(±3) → 테마 중립화(k = 5, 안정성 제외) → 팩터 F → 이력 축소(D-010) → 국가·묶음 안 F 재표준화 → 가중합(빠진 팩터 0) → 저평가·수익성 필수, 유효 팩터 ≥ 3
  - 원자재 테마의 성장성 예외는 두지 않는다
- 이유: 독립 기준 이상 종목 31 → 14, 거짓 음성 41 → 27, sanity 5/22 → 17/22. 11번 6절의 '문제없음' 반례(P5·P12·P13)를 버텼다. 대안(이익 CAGR, 매출만, 낙폭 유지)은 모두 다른 지표가 나빠졌다.
- 감수하는 것: 꾸준히 성장하는 기업의 저평가 이익이 10~13% 깎인다(순위 영향은 중앙값 1~2위). 0.78은 미국·국내 세율 근사값이다.
- 다시 열 조건: 독립 기준 이상 종목이 R11 측정치(14)보다 늘어난 라운드가 나오거나, 현금흐름 수집 완료 시(D-009).

### D-003 점수 표시는 순위·백분위 구간으로 바꾼다
- 날짜 / 관련 이슈: 2026-10-27 / P3, P10, P11, U-1(표시 쪽)
- 결정:
  - 주 표시: **"같은 시장 N개 중 M위 (상위 p%)"**. 게이지와 5단계 라벨은 백분위 20% 구간. Φ로 만든 0~100 숫자는 화면에서 뺀다.
  - 홈 '매력도 순위'는 general 묶음만, 금융은 별도 탭.
  - 종목 화면에 **소속 테마의 위치**를 함께 보인다: "이 테마는 같은 시장 테마 중 저평가·수익성·성장성 몇 번째 구간" (테마 평균 F의 백분위). 테마 안 1등이 테마 자체가 약해서 1등인지 사용자가 볼 수 있게 한다.
  - 배지: 일회성(순이익 > 1.2 × 영업이익), 결산 시점(최빈 결산일과 > 6개월), 재무 이력 < 3년. 기존 원자재 배지 유지.
  - 성장 프리셋·성장 팩터 설명에 "성장 노출을 보여 줄 뿐, 기대수익을 뜻하지 않는다"를 적는다(D-005).
- 이유: Φ 점수와 실제 백분위가 최대 17.6점 어긋난다. 가중치 ±0.1에 top10이 흔들리는 문제(P10)는 모델로 줄지 않아서, 순위를 정밀한 값처럼 보이지 않게 하는 쪽이 정직하다. 30개 금융 묶음의 거친 해상도는 "1계단"으로 그대로 드러나는 편이 낫다.
- 감수하는 것: 30개 묶음에서 한 계단 = 3.3%p라 작은 차이도 순위가 바뀐다.
- 다시 열 조건: 묶음 표본이 100개를 넘거나, R7(배지 비율) 실패 시.

### D-004 비주식·지주·금융 연결은 설정으로 분리한다
- 날짜 / 관련 이슈: 2026-10-27 / P4
- 결정: GLD·IAU 등 신탁은 점수 없음, 지주회사 테마는 `scoring: none`, 다우기술은 금융(증권·자산운용) 묶음, 리츠는 기존대로 점수 없음. 수익성 팩터는 필수로 둔다.
- 이유: 설정만으로 반례 상위 종목(GLD·IAU·SK스퀘어·다우기술)이 바로 빠진다. 정상 적자 성장 기업은 수익성 필수로 빠지지 않는다(11번 P4: 영업적자인데 점수 유지 미국 27·국내 49).
- 감수하는 것: 이름에 '홀딩스'가 붙은 사업형 지주(피에스케이홀딩스, 한국앤컴퍼니)는 지주 테마가 아니면 점수를 받는다. 다우기술은 금융 안에서도 2위권이다.
- 다시 열 조건: 지주회사 테마 밖 사업형 지주가 top10에 2개 이상.

### D-005 성장성은 +방향 유지, 인수 성장은 감수
- 날짜 / 관련 이슈: 2026-10-27 / R1-9, 10번 Fama-French 지적
- 결정: 매출 CAGR에 +를 준다. 인수로 늘어난 매출과 자체 성장을 구분하지 않는다.
- 이유: 09는 "수익률 예측이 아니다"라고 정의하고, "성장" 프리셋이 약속하는 것은 성장 노출이다. Fama-French 투자 팩터는 기대수익을 설명하는 것이라 약속하는 대상이 다르다. 인수와 자체 성장을 가를 데이터가 없다.
- 감수하는 것: 한국타이어앤테크놀로지처럼 인수로 매출이 크게 는 종목이 성장 상위에 든다. 매출 CAGR과 자산 CAGR 상관 0.52~0.62.
- 다시 열 조건: 인수·사업결합 공시 데이터를 수집하면.

### D-006 수익성–성장성 상관 0.42~0.48은 감수한다
- 날짜 / 관련 이슈: 2026-10-27 / R1-7
- 결정: R11 성장성 지표를 그대로 둔다.
- 이유: 대안 2개(이익 CAGR, 매출만)는 상관을 0.29~0.46으로 낮추지만 거짓 음성이나 이상 종목이 늘었다. 돈을 잘 버는 회사가 이익도 잘 늘리는 건 실제 현상이라 상관을 0으로 만드는 게 목표가 아니다.
- 감수하는 것: 균형 프리셋에서 수익성·성장성이 일부 겹쳐 세진다.
- 다시 열 조건: 상관이 0.6을 넘는 라운드가 나오면.

### D-007 작은 가중치의 실효 0은 감수하고 문서에 적는다
- 날짜 / 관련 이슈: 2026-10-27 / R1-10
- 결정: 가중치는 그대로 두고, 09에 프리셋별 **실효 가중치 표**를 함께 적는다.

### D-010 재무 이력 부족은 데이터 보완 + 축소로 처리
