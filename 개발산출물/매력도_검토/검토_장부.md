# 매력도 모델 검토 장부

> 매 검토 라운드의 입력이자 출력이다. 라운드 검토자는 **열린 이슈에만 추가**할 수 있고, 결정 기록은 모델 담당자(나)만 쓴다.
> 기준 문서는 `개발산출물/09_매력도_점수_정의서.md` 하나뿐이다. 모델이 바뀌면 09를 먼저 고치고, 여기 라운드 기록에 09의 커밋 SHA를 남긴다.

## 0. 종료 조건

아래를 모두 만족하면 검토를 멈춘다.

1. **관점이 서로 다른 2라운드 연속**으로 새 치명·높음 이슈가 0개
2. `sanity_cases.yaml`의 `required` 케이스 전부 통과
3. 열린 이슈 중 치명·높음이 0개 (남은 중간·낮음은 결정 기록으로 옮기거나 다음 버전으로 미룸)

> 종료는 "논리적 흠이 최소화됐다"는 뜻이지 "수익률이 좋다"는 뜻이 아니다. 수익률 검증은 점수 이력이 쌓인 뒤 따로 한다(10번 보고서 7절).

## 3. 결정 기록

알고 받아들인 흠과 설계 선택. **라운드 검토자는 새 증거(이전에 없던 수치·반례)가 있을 때만 다시 열 수 있다.** 다시 열 때는 그 새 증거를 반드시 적는다.

### 형식

```
### D-000 제목
- 날짜 / 관련 이슈:
- 결정:
- 이유:
- 감수하는 것 (알려진 반례):
- 다시 열 조건: (예: 순차입금 수집 완료 시, 반례 N개 이상 발견 시)
```

### D-001 (예시 — 실제 결정 후 고쳐 쓸 것) EV 수집 전까지 저평가 분모는 시가총액
- 날짜 / 관련 이슈: 2026-10-27 / P8
- 결정: 순차입금을 수집하기 전까지 저평가 지표 분모는 시가총액을 유지한다.
- 이유: 지금 DB에 순차입금 필드가 없다.
- 감수하는 것: 부채가 많은 통신주(T·VZ)가 가치 상위에 남는다. `sanity_cases.yaml`의 `T-value`는 `known_fail`.
- 다시 열 조건: 순차입금 수집 완료 시.
