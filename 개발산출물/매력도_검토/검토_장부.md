# 매력도 모델 검토 장부

> 매 검토 라운드의 입력이자 출력이다. 라운드 검토자는 **열린 이슈에만 추가**할 수 있고, 결정 기록은 모델 담당자만 쓴다.
> 기준 문서는 `개발산출물/09_매력도_점수_정의서.md` 하나뿐이다. 모델이 바뀌면 09를 먼저 고치고, 여기 라운드 기록에 09의 커밋 SHA를 남긴다.
> 결정 D-001~D-013은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-27, 근거: 10·11번 보고서). 검토자와 다른 세션이 결정했으므로 검토 분리는 유지된다.
> D-014·D-017은 모델 담당자가 결정했고, D-015·D-016은 모델 담당자의 위임("최선의 선택")으로 수정 1 세션의 Claude가 근거 수치와 함께 적었다(2026-10-27).
> D-018~D-023은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-27, 근거: 라운드 2 보고서). 라운드 2 검토 세션과 다른 세션이다.

## 0. 종료 조건

아래를 모두 만족하면 검토를 멈춘다.

1. **관점이 서로 다른 2라운드 연속**으로 새 치명·높음 이슈가 0개
2. `sanity_cases.yaml`의 `required` 케이스 전부 통과 (`known_fail`은 결정 번호가 있으면 통과로 본다)
3. 열린 이슈 중 치명·높음이 0개 (남은 중간·낮음은 결정 기록으로 옮기거나 다음 버전으로 미룸)

> 종료는 "논리적 흠이 최소화됐다"는 뜻이지 "수익률이 좋다"는 뜻이 아니다. 수익률 검증은 점수 이력이 쌓인 뒤 따로 한다(D-013).
> 연속 라운드 계산은 D-023을 따른다.

## 3. 결정 기록

알고 받아들인 흠과 설계 선택. **라운드 검토자는 새 증거(이전에 없던 수치·반례)가 있을 때만 다시 열 수 있다.** 다시 열 때는 그 새 증거를 반드시 적는다.

### D-001 EV 수집 전까지 저평가 분모는 시가총액
- 날짜 / 관련 이슈: 2026-10-27 / P8, R1-1 잔여
- 결정: 순차입금·영업권을 수집하기 전까지 저평가 분모는 시가총액, B/P는 장부가 그대로 쓴다. 수집은 D-011의 PR 7로 한다.
- 이유: DB에 순차입금·영업권 필드가 없다. 세후 보수 이익(D-002)으로 부채 효과를 일부 줄였지만 시총 분모로는 완전히 고칠 수 없다(11번 2절 P8).
- 감수하는 것: T 가치 1위, VZ 가치 2위·균형 9위, 사업형 지주(한일홀딩스 가치 16위, 한국앤컴퍼니 균형 7위)가 다소 싸 보인다. 합병 장부가가 큰 종목(SIRI)의 B/P 과대.
- 다시 열 조건: 순차입금 또는 비지배지분 순이익 수집 완료 시.

  - 저평가: ① 세후 보수 이익/시총 — 해마다 e = min(지배주주 순이익, 0.78 × 영업이익), 그다음 min(최신 e, 3년 평균 e). 순이익이 없으면 0.78 × 영업이익 ② B/P ③ 가치 함정 신호 — 2년 비교 5개(영업흑자·영업이익↑·매출↑·영업이익률↑·부채/자산↓, 이익 관련 2개는 2년 전 흑자일 때만) 중 '예' 비율의 로버스트 Z를 **0 이하로 잘라 감점만**
  - 수익성: 영업이익/총자산, 영업이익률
  - 성장성: 2년 매출 CAGR, 2년 영업이익 변화 ÷ 2년 전 총자산(**2년 전 영업흑자일 때만**, 아니면 비움)
  - 안정성: (2 × 변동성 + 1 × 부채/자산) / 3. 1년 최대 낙폭은 뺀다
  - 주가 흐름: 12-1개월 수익률(그대로)
  - 금융 묶음: 11번 4절 금융 행 그대로
  - 합산: 로버스트 Z(±3) → 테마 중립화(k = 5, 안정성 제외) → 팩터 F → 이력 축소(D-010) → 국가·묶음 안 F 재표준화 → 가중합(빠진 팩터 0) → 저평가·수익성 필수, 유효 팩터 ≥ 3
  - 원자재 테마의 성장성 예외는 두지 않는다
- 이유: 독립 기준 이상 종목 31 → 14, 거짓 음성 41 → 27, sanity 5/22 → 17/22. 11번 6절의 '문제없음' 반례(P5·P12·P13)를 버텼다. 대안(이익 CAGR, 매출만, 낙폭 유지)은 모두 다른 지표가 나빠졌다.
- 감수하는 것: 꾸준히 성장하는 기업의 저평가 이익이 10~13% 깎인다(순위 영향은 중앙값 1~2위). 0.78은 미국·국내 세율 근사값이다.

- 감수하는 것: 30개 묶음에서 한 계단 = 3.3%p라 작은 차이도 순위가 바뀐다.

### D-018 저평가 팩터는 B/P만 테마 중립화한다 (V1)

### D-019 순위 정규 점수(RN)는 V1 다음 PR로 조건부 채택
- 날짜 / 관련 이슈: 2026-10-27 / R2-1 (위임으로 Claude 작성)
- 결정: 로버스트 Z(±3)를 **같은 시장·묶음 안 순위 정규 점수 z = Φ⁻¹((순위 − 0.5) / n)**로 바꾼다(방향 −는 부호 반대, 가치 함정 신호는 0 이하로 자름, 중립화와 뒤 자르기는 그대로). 상장 종목 참고 점수(`reference_score.py`)도 같은 식(표본 안 순위)으로 맞춘다. 단, **V1(D-018)을 먼저 배포·측정한 뒤 별도 PR**로 넣고, 아래를 모두 지킬 때만 유지한다.
  - required 전부 통과(특히 MU-value)
  - R10(D-021 경계) 통과
  - 이상 + 거짓 음성 합이 V1 단독 측정치 + 3 이하(잡음 폭 안)
  - 하나라도 어기면 RN을 되돌리고 R2-1은 '결정(D-019)'으로 감수한다.
- 이유: 자른 뒤 중립화하면 잘린 묶음(지표마다 상위 3~10%) 안 순서가 테마 약함 순서로 바뀐다(Spearman −0.47~0.31). 위험·성장 프리셋 상위 후보의 순서라 사용자가 직접 본다. 라운드 2 측정에서 RN + V1은 required 32/32, 이상 14·거짓 음성 27, 표시 모순 15·17 → 7·7. 다만 독립 기준 합은 V1 단독(38)보다 3 높고 RN 단독은 MU-value가 실패해서 조건을 둔다.
- 감수하는 것: 원값의 크기 정보가 사라진다(+1,093%와 +154%가 순위 차이만큼만 벌어짐). 의도된 성질이다.
- 주의: sanity `CLIP-order`는 RN을 겨냥한 규칙(independent: false)이라 회귀 방지용으로만 쓰고, RN이 낫다는 근거로 세지 않는다.
- 다시 열 조건: 묶음 표본이 50개 미만으로 줄어 순위 해상도가 거칠어지면.
