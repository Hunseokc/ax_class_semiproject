# 매력도 모델 검토 장부

> 매 검토 라운드의 입력이자 출력이다. 라운드 검토자는 **열린 이슈에만 추가**할 수 있고, 결정 기록은 모델 담당자만 쓴다.
> 기준 문서는 `개발산출물/09_매력도_점수_정의서.md` 하나뿐이다. 모델이 바뀌면 09를 먼저 고치고, 여기 라운드 기록에 09의 커밋 SHA를 남긴다.
> 결정 D-001~D-013은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-27, 근거: 10·11번 보고서). 검토자와 다른 세션이 결정했으므로 검토 분리는 유지된다.
> D-014·D-017은 모델 담당자가 결정했고, D-015·D-016은 모델 담당자의 위임("최선의 선택")으로 수정 1 세션의 Claude가 근거 수치와 함께 적었다(2026-10-27).
> D-018~D-023은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-27, 근거: 라운드 2 보고서). 라운드 2 검토 세션과 다른 세션이다.
> D-024~D-035는 모델 담당자의 위임으로 Claude가 작성했다(2026-10-27, 근거: 라운드 3 보고서, 외부 AI의 장부 검토, `근거_정렬표.md`). 라운드 3 검토 세션과 다른 세션이다. D-033의 '5년 수집·분기 재무로 3층 해결'은 모델 담당자 결정이다.
> D-036~D-038은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-28, 근거: 수정 3 보고, `sanity_수정3.md`). 수정 3 세션과 다른 세션이다.
> D-039~D-042는 모델 담당자의 위임으로 Claude가 작성했다(2026-10-28, 근거: 라운드 4 보고서). 라운드 4 검토 세션과 다른 세션이다.
> D-043은 모델 담당자의 위임으로 Claude가 작성했다(2026-10-28, 근거: 수정 4 보고, `sanity_수정4.md`, `다음_할_일_2026-10-28.md`). 수정 4 세션과 다른 세션이다.

## 0. 종료 조건

아래를 모두 만족하면 검토를 멈춘다.

**1단계 — 모순 최소화**

1. **관점이 서로 다른 2라운드 연속**으로 새 치명·높음 이슈가 0개 (연속 계산은 D-035)
2. `sanity_cases.yaml`의 `required` 케이스 전부 통과. 결과는 **통과 / 감수한 실패(known_fail·결정 번호) / target 실패 / 미검증** 네 칸으로 따로 적는다(D-030). 감수한 실패는 종료를 막지 않지만 '통과' 수에 합치지 않는다.
3. 열린 이슈 중 치명·높음이 0개 (남은 중간·낮음은 결정 기록으로 옮기거나 다음 버전으로 미룸)

**2단계 — 근거** (D-030·D-031)

4. `근거_정렬표.md`의 모든 지표·처리 규칙이 A/B/C 등급을 갖고, B는 차이와 이유, C는 '근거 약함' 표시나 결정 기록이 있다.
5. 종료 판정 라운드는 조정에 쓰지 않은 데이터로 확인한다 — 마지막 모델 변경 뒤 2주 이상 지난 as_of에서 required 전부 통과, 그리고 봉인 반례(`봉인_반례.yaml`)를 열어 결과를 기록하고 위반에서 치명·높음이 없다.

> 종료는 "논리적 흠이 최소화됐다"는 뜻이지 "수익률이 좋다"는 뜻이 아니다. 수익률 검증은 점수 이력이 쌓인 뒤 따로 한다(D-013).
> 연속 라운드 계산은 D-035를 따른다(D-023 대체).

## 3. 결정 기록

알고 받아들인 흠과 설계 선택. **라운드 검토자는 새 증거(이전에 없던 수치·반례)가 있을 때만 다시 열 수 있다.** 다시 열 때는 그 새 증거를 반드시 적는다.

### D-001 EV 수집 전까지 저평가 분모는 시가총액
- 날짜 / 관련 이슈: 2026-10-27 / P8, R1-1 잔여
- **개정(2)**: 순차입금·영업권 수집은 D-033으로 하고, EV 분모 채택은 M1 측정 뒤 결정한다(D-035).
- 결정: 순차입금·영업권을 수집하기 전까지 저평가 분모는 시가총액, B/P는 장부가 그대로 쓴다. 수집은 D-011의 PR 7로 한다.
- 이유: DB에 순차입금·영업권 필드가 없다. 세후 보수 이익(D-002)으로 부채 효과를 일부 줄였지만 시총 분모로는 완전히 고칠 수 없다(11번 2절 P8).
- 감수하는 것: T 가치 1위, VZ 가치 2위·균형 9위, 사업형 지주(한일홀딩스 가치 16위, 한국앤컴퍼니 균형 7위)가 다소 싸 보인다. 합병 장부가가 큰 종목(SIRI)의 B/P 과대.
- 다시 열 조건: 순차입금 또는 비지배지분 순이익 수집 완료 시.

### D-002 모델 본체는 11번 R11안을 채택한다
- 날짜 / 관련 이슈: 2026-10-27 / P1·P2·P5·P6·P7·P12·P13, R1-1~R1-4
- **개정(2)**: 다시 열 조건(이상 > 16) 충족에 따른 재개는 D-041 순서로 처리한다 — 모델은 지금 바꾸지 않고, S1·S2 두 날짜 모두 > 16이면 M1 비교 뒤 결정 5에서 정한다.
- **개정**: 중립화 범위는 D-018, 정규화 방식은 D-019, 다시 열 조건의 경계는 D-021이 이 결정보다 우선한다.
- 결정: 11번 보고서 4절 R11 뼈대를 그대로 모델 v2로 한다.
  - 저평가: ① 세후 보수 이익/시총 — 해마다 e = min(지배주주 순이익, 0.78 × 영업이익), 그다음 min(최신 e, 3년 평균 e). 순이익이 없으면 0.78 × 영업이익 ② B/P ③ 가치 함정 신호 — 2년 비교 5개(영업흑자·영업이익↑·매출↑·영업이익률↑·부채/자산↓, 이익 관련 2개는 2년 전 흑자일 때만) 중 '예' 비율의 로버스트 Z를 **0 이하로 잘라 감점만**
  - 수익성: 영업이익/총자산, 영업이익률
  - 성장성: 2년 매출 CAGR, 2년 영업이익 변화 ÷ 2년 전 총자산(**2년 전 영업흑자일 때만**, 아니면 비움)
  - 안정성: (2 × 변동성 + 1 × 부채/자산) / 3. 1년 최대 낙폭은 뺀다
  - 주가 흐름: 12-1개월 수익률(그대로)
  - 금융 묶음: 11번 4절 금융 행 그대로
  - 합산: 로버스트 Z(±3) → 테마 중립화(k = 5, 안정성 제외) → 팩터 F → 이력 축소(D-010) → 국가·묶음 안 F 재표준화 → 가중합(빠진 팩터 0) → 저평가·수익성 필수, 유효 팩터 ≥ 3
  - 원자재 테마의 성장성 예외는 두지 않는다
- 이유: 독립 기준 이상 종목 31 → 14, 거짓 음성 41 → 27, sanity 5/22 → 17/22. 11번 6절의 '문제없음' 반례(P5·P12·P13)를 버텼다. 대안(이익 CAGR, 매출만, 낙폭 유지)은 모두 다른 지표가 나빠졌다.

### D-003 점수 표시는 순위·백분위 구간으로 바꾼다
- 날짜 / 관련 이슈: 2026-10-27 / P3, P10, P11, U-1(표시 쪽)

### D-019 순위 정규 점수(RN)는 V1 다음 PR로 조건부 채택
- 날짜 / 관련 이슈: 2026-10-27 / R2-1 (위임으로 Claude 작성)
- 결정: 로버스트 Z(±3)를 **같은 시장·묶음 안 순위 정규 점수 z = Φ⁻¹((순위 − 0.5) / n)**로 바꾼다(방향 −는 부호 반대, 가치 함정 신호는 0 이하로 자름, 중립화와 뒤 자르기는 그대로). 상장 종목 참고 점수(`reference_score.py`)도 같은 식(표본 안 순위)으로 맞춘다. 단, **V1(D-018)을 먼저 배포·측정한 뒤 별도 PR**로 넣고, 아래를 모두 지킬 때만 유지한다.
  - required 전부 통과(특히 MU-value)
  - R10(D-021 경계) 통과
  - 이상 + 거짓 음성 합이 V1 단독 측정치 + 3 이하(잡음 폭 안)
  - 하나라도 어기면 RN을 되돌리고 R2-1은 '결정(D-019)'으로 감수한다.
- 이유: 자른 뒤 중립화하면 잘린 묶음(지표마다 상위 3~10%) 안 순서가 테마 약함 순서로 바뀐다(Spearman −0.47~0.31). 위험·성장 프리셋 상위 후보의 순서라 사용자가 직접 본다. 라운드 2 측정에서 RN + V1은 required 32/32, 이상 14·거짓 음성 27, 표시 모순 15·17 → 7·7. 다만 독립 기준 합은 V1 단독(38)보다 3 높고 RN 단독은 MU-value가 실패해서 조건을 둔다.
- 감수하는 것: 원값의 크기 정보가 사라진다(+1,093%와 +154%가 순위 차이만큼만 벌어짐). 의도된 성질이다.
- 주의: sanity `CLIP-order`는 RN을 겨냥한 규칙(independent: false)이라 회귀 방지용으로만 쓰고, RN이 낫다는 근거로 세지 않는다.
- 다시 열 조건: 묶음 표본이 50개 미만으로 줄어 순위 해상도가 거칠어지면.

### D-030 sanity 집계 분리, 기준 고정, 봉인 반례, 배포 sanity
- 날짜 / 관련 이슈: 2026-10-27 / U-6, U-7, 외부 검토(같은 데이터로 기준·모델을 함께 조정한다는 지적) (위임으로 Claude 작성)
- 결정:
  - **집계 분리**: sanity 결과는 `통과 / 감수한 실패(known_fail·결정 번호) / target 실패 / 미검증(데이터 없음·실행 불가)` 네 칸으로 적는다. 라운드 기록의 sanity 칸도 이 형식으로 쓴다.
  - **기준 고정**: 합격선(R10 등 수치 경계)은 후보 모델을 비교한 그 as_of 데이터로 바꾸지 않는다. 바꾸려면 다른 as_of(2주 이상 떨어진 날)에서 잰 잡음 폭을 근거로 한다.
  - **봉인 반례**: 모델 조정에 참여하지 않은 쪽(다른 AI 또는 장부·보고서를 읽지 않은 새 세션)이 점수를 보기 전에 상식 반례 20~30개(종목·프리셋·기대 방향과 이유)를 `봉인_반례.yaml`로 쓰고 커밋한다. 종료 판정 라운드에서만 열어 결과를 그대로 기록하고, 위반마다 이슈를 연다. 그 뒤로는 봉인 반례를 통과시키려고 모델을 바꾸지 않는다(바꾸면 새 봉인 목록을 쓴다).
  - **holdout as_of**: 종료 판정 라운드는 마지막 모델 변경 뒤 2주 이상 지난 as_of로 sanity 전체를 다시 돌린다.
  - **배포 sanity**: `sanity_cases.yaml`을 배포 이미지에 넣고, 점수 재계산 뒤 Cloud Run Job으로 sanity를 돌려 결과를 로그·DB 표에 남긴다. 접속 정보가 컨테이너 밖으로 나오지 않는다.
- 이유: sanity 통과는 정해 둔 사례를 통과했다는 뜻이지 순위의 신뢰도 증거가 아니다. 같은 데이터로 모델과 기준을 함께 맞추면 그 데이터에 맞춰진다. 지금 할 수 있는 독립 확인은 다른 날짜와 미리 봉인한 반례뿐이다.
- 감수하는 것: holdout as_of도 같은 종목·비슷한 재무라 완전한 독립 표본은 아니다. 진짜 독립 검증은 D-013 수익률 비교다.
- 다시 열 조건: D-013 점수 이력이 6개월 쌓이면 수익률 기반 검증을 종료 조건에 추가할지 다시 본다.

### D-040 이력 축소는 'FY 개수'가 아니라 '보수 규칙을 쓸 수 있는가'로 정한다
- 날짜 / 관련 이슈: 2026-10-28 / R4-1, 라운드 4 3-3, D-010 개정 (위임으로 Claude 작성)
- 개정: D-010의 '재무 FY가 3개 미만이면 저평가 F × (FY 수 / 3)'을 이 결정이 대체한다.
- 새 증거: FY 1개와 2개는 보수 규칙 면에서 같다 — 둘 다 3년 평균 이익(min 규칙)과 가치 함정 신호(t−2 필요)를 쓸 수 없다. 그런데 축소율만 1/3과 2/3로 달라, 데이터가 더 완전한 DB(대한조선 FY2024 전기값 있음)가 required를 실패했다(가치 14위 vs 42위).
- 결정: 저평가 F 축소를 **보수 규칙을 쓸 수 있는지**로 정한다.
  - 3년 평균 이익과 가치 함정 신호를 **둘 다 쓸 수 없으면** × 1/3
  - **하나만** 쓸 수 있으면 × 2/3
  - 둘 다 쓸 수 있으면 축소 없음
  - 지금 코드에서는 두 규칙 모두 t−2 FY가 있어야 쓸 수 있어(`score_metrics.sql`의 e_cons·trap_signal), 실제로는 **FY 1·2개 × 1/3, 3개 이상 축소 없음**이 된다. × 2/3는 FY는 3개인데 한 해 이익이 비었거나 가치 함정 신호가 3개 미만으로만 계산되는 드문 경우다.
  - 5년 수집 뒤에도 기준은 3년 평균(D-002)이므로 그대로 둔다. 정상화 기간을 5년으로 바꾸는 것은 M1 후보다.
- 이유: D-010이 축소를 둔 목적은 "이력이 짧은 종목이 보수 규칙을 피해 저평가 상위로 가는 것"을 막는 것이다. 그러면 축소 기준도 FY 개수가 아니라 보수 규칙을 피했는지여야 한다. 이 기준은 D-010의 목적에서 나온 것이고 sanity 결과에 맞춘 것이 아니다. 다만 대한조선 케이스를 통과시키는 방향이라, 판정은 기준 스냅샷 S1·S2(D-041)에서 다시 확인한다.
- 감수하는 것: FY 2개 종목의 저평가가 지금(× 2/3)보다 더 줄어든다(× 1/3). 축소율이 두 규칙의 사용 가능 여부에 묶여, 규칙이 바뀌면(M1의 정상화 5년 등) 축소도 같이 바뀐다. 근거 등급은 그대로 C(자체 규칙)다.
- 다시 열 조건: 축소 때문에 우량 신규 상장 종목이 거짓 음성으로 3개 이상 잡히거나, S1·S2에서 DAEHAN이 실패하면.

### D-043 표본 밖이라 비어 있는 케이스는 '통과'가 아니라 '미검증'으로 센다
- 날짜 / 관련 이슈: 2026-10-28 / D-030 보완, 수정 4 보고(SIRI·OSK) (위임으로 Claude 작성)
