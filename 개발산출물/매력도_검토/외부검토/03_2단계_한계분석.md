# 2단계 — 구조적 한계와 가정 오류 (같은 대화 B)

## 2-1. 백지 분석 (첨부 없이)

```
이제 이 모델이 실제 투자 판단에 쓰일 때의 치명적인 구조적 한계와 가정상의 오류를 심층 분석하라.

[규칙]
1. 먼저 이 모델이 암묵적으로 깔고 있는 가정을 목록으로 만들고, 각 가정이 깨지는 구체적 상황(업종·회계 처리·시장 상황)을 붙여라.
2. 문제마다 둘 중 하나로 분류하라.
   - 논리 오류: 앱 목적 안에서도 점수가 사용자를 잘못 이끄는 것
   - 범위 밖 한계: 재무제표 기반 참고 점수라는 목적상 감수할 수밖에 없는 것(예: 지정학 사건)
3. 심각도는 "사용자가 이 점수를 믿고 행동했을 때 얼마나 잘못된 판단을 하게 되는가"로 매겨라(치명/높음/중간/낮음).
4. 실제 종목 예시를 들면 좋지만, 최근 수치를 쓰면 출처를 적고 확실하지 않으면 '확인 필요'라고 써라.
5. 심각도 순 상위 10개만, 아래 표로 답하라.
   열: # | 문제 | 분류(논리 오류/범위 밖) | 깨지는 가정 | 예시 상황 | 심각도
6. 개선안은 아직 내지 마라.
```

## 2-2. 알려진 한계와 대조 (첨부B를 이때 처음 준다)

```
첨부한 목록은 모델 담당자가 이미 알고 감수하기로 한 한계다.
1. 네가 앞에서 낸 10개를 각각 '이미 알려짐(목록의 어느 항목)' / '부분적으로 알려짐(무엇이 새로운지)' / '새로움'으로 표시하라.
2. 목록에 있는 감수 결정 중 네가 보기에 감수하면 안 되는 것이 있다면, 최대 3개까지 이유와 함께 적어라.
3. 표로만 답하라. 열: # | 판정 | 대응 항목 | 새로운 점(있을 때)
```
