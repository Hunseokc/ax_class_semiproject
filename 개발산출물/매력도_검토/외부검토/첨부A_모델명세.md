# 매력도 모델 명세

> 원본 `09_매력도_점수_정의서.md`에서 계산 규칙만 기계적으로 발췌했다. 변경 이력·사례·한계 절은 뺐다.

> 매력도는 **비교 표본(노출 종목 + 비교군) 안에서 같은 시장끼리(금융은 금융끼리) 비교한 상대적 위치를 나타내는 팩터 점수**이며, 수익률 예측이나 투자 권유가 아니다. 화면(종목 상세·주식 리스트 하단)과 API 응답(`disclaimer`)에 같은 문구를 표시한다.

**앱 범위**: 국내·미국 상장사 약 600종목(테마 39개 × 국가별 시가총액 상위 최대 10 + 노출 종목). 재무제표(연간 FY, DART·SEC)와 일봉·시가총액만 쓴다. 미래 추정치(컨센서스)·분기 재무는 점수에 쓰지 않는다. 수익률 백테스트용 점수 이력은 아직 없다.

## 2. 지표 정의

**재무 FY 고르기**: 자산과 이익(순이익 또는 영업이익)이 있는 FY만 쓴다 — 일부 칸만 들어온 최신 FY(예: yfinance 보완으로 순이익만 있는 CLX FY2026)는 건너뛴다. t = 그중 최신, t−1·t−2 = 바로 뒤 FY보다 결산일이 330~400일 앞선 FY다(결산월을 바꾸며 끼어든 행 — 신영증권 2025-03-31 — 은 건너뜀). 이어지는 FY 수(1~3)를 `fy_count`로 남긴다.

**해마다 저평가 이익 e** = min(지배주주 순이익, 0.78 × 영업이익). 순이익이 영업이익보다 큰 해(지분 매각·평가이익 등 일회성 — KCC 3.6배, 사람인 5.5배, WDC 2.1배)는 세후 영업이익 수준으로 잘리고, 이자·비지배 몫이 빠진 순이익이 더 작으면 순이익을 쓴다. 순이익이 없으면 0.78 × 영업이익, 영업이익이 없으면 순이익. 0.78 = 1 − 22%(미국 21%와 국내 지방세 포함 24.2% 사이 근사, `scoring.yaml after_tax`). 금융은 순이익. 수익성·성장성의 이익 p = 영업이익(금융은 순이익).

## 3. 정규화

- 점수 묶음(family) = 주 테마의 `scoring`. **financial(금융)은 금융끼리**, 그 밖(주 테마가 없어도)은 general끼리 표준화한다. 금융은 PER·PBR이 구조적으로 낮아 일반 기업과 섞으면 저평가가 늘 상위가 된다(2026-10-26 변경 전 KB금융 참고 점수 99.15 — 유효 팩터 3개로 일반 기업과 비교한 값).
- 지표마다 **순위 정규 점수(RN) z = Φ⁻¹((r − 0.5) / n)**. r = 같은 국가·묶음 안 원값 오름차순 순위(같은 값은 평균 순위), n = 그 지표 값이 있는 종목 수. 표본이 1개면 z = 0.
- 방향이 −인 지표(변동성·부채/자산)는 부호를 뒤집는다. 감점 전용 지표(가치 함정 신호)는 **0 이하로** 자른다. n = 300이면 꼬리가 ±2.9 안이라 따로 자르지 않는다.

## 4. 섹터 중립화

- **z_adj = z − (n / (n + k)) × 같은 국가·같은 주 그룹 내 z 평균**. n은 같은 국가의 주 그룹 구성원 중 그 지표의 z가 있는 종목 수, k = `shrinkage_k`(기본 5).
- **그룹 평균에는 자기 자신이 포함된다.** 그래서 그룹이 작을수록(n이 작을수록) 평균을 덜 빼도록 n/(n+k)로 축소한다.
- 주 테마가 없거나 n = 1이면 z_adj = z. **중립화 뒤에도 [−3, 3]으로 자른다**(2026-10-26 변경). 그룹 평균이 크게 음수인 그룹(적자 종목이 섞인 그룹)에서 3을 넘는 값이 나왔다 — 변경 전 Alcoa EPS 변화 z_adj 3.68.
- 보조 테마(11절)는 중립화에 쓰지 않는다.

중립화하지 않는 지표:

| 지표 | 이유 |
|---|---|
| 안정성 2개(변동성·부채/자산) | 업종 특성으로 주가가 크게 출렁이는 것도 위험이므로 그대로 반영한다 |
| 세후 보수 이익/시총 | 테마 평균의 시점 간 상관이 0.50~0.72로 덜 구조적이다. 비싼 테마 안 가장 싼 종목(경기 정점·분류 어긋남)을 올리지 않는다 |
| 가치 함정 신호 | 감점 전용이라 테마 평균을 빼면 같은 테마에 나쁜 종목이 많을 때 가점이 생긴다 |

B/P는 테마 차이가 회계 구조(테마 평균의 시점 간 상관 0.97~1.00, 미국 테마 평균 ROA와 −0.77)라 중립화한다. 수익성·성장성·주가 흐름은 모든 지표를 중립화한다. 근거 측정은 `개발산출물/매력도_검토/라운드_2_통계.md` 4-3·4-4.

## 5. 합산과 점수

- 팩터 점수 F = 해당 팩터의 유효 지표 z_adj **가중 평균**(지표 1개 이상). 가중치는 안정성의 변동성 2 · 부채/자산 1, 나머지 지표는 1.
- **재무 이력 축소**: 저평가의 보수 규칙 두 개 — **3년 평균 이익**(min(최신 e, 3년 평균 e))과 **가치 함정 신호**(t−2 필요, 금융은 해당 없음이라 t−2만 있으면 쓸 수 있음으로 셈) — 중 쓸 수 있는 수로 저평가 F를 줄인다: 둘 다 못 쓰면 × 1/3, 하나만 쓰면 × 2/3, 둘 다 쓰면 그대로. 이력이 짧은 종목이 보수 규칙을 피해 저평가 상위로 가는 것을 막는 것이 목적이라, 축소 기준도 FY 개수가 아니라 규칙을 피했는지다. 지금 두 규칙 모두 t−2 FY가 있어야 쓸 수 있어 실제로는 **FY 1·2개 × 1/3, 3개 이상 그대로**이고, × 2/3는 FY가 3개인데 한 해 이익이 비었거나 함정 신호를 3개 미만으로만 셀 수 있는 드문 경우다. 2026-10-28까지는 × (FY 수 / 3)이라 FY 1개와 2개가 보수 규칙 면에서 같은데 축소율만 1/3·2/3로 달라, 전기값으로 FY가 하나 더 있는 DB에서 대한조선이 가치 14위(required 실패)가 됐다. 근거 등급은 C(자체 규칙). `score_metrics.sql` `value_rules`(0~2) → `data_quality.value_rules`.
- **재표준화**: 같은 country·묶음 안에서 팩터마다 F를 평균 0·표본표준편차 1로 다시 맞춘다(Fs). `stock_scores.value_score` 등은 Fs다.
- 종합 = Σ(w_f × Fs_f). **빠진 팩터는 0(중립)**이고 가중치를 다시 나누지 않는다. **저평가·수익성 팩터가 없거나 유효 팩터가 3개 미만이면 점수는 NULL**이고 사유를 `data_quality.score_null_reason`(코드 `score_null_code`)에 기록한다. 재무가 없어 저평가·수익성을 못 구하면(`no_financials`) 상세 화면은 요소값·레이더 없이 **"재무 정보가 없어 표기할 수 없습니다"**만 보인다. `factor_coverage`는 유효 팩터 수(0~5)다.
- **점수 = 같은 country·묶음·프리셋 안 백분위 100 × (n − 순위) / n** (표본이 1개면 50). "상위 p%" = 100 × 순위 / n과 정확히 맞물려 **80 이상 = 상위 20%**다. 1위도 100 미만이다.

## 8. 금융 묶음 (종합 점수 대신)

금융 묶음(은행·카드, 보험, 증권·자산운용)은 **종합 점수·프리셋 순위·5단계 라벨을 내지 않는다**(`stock_scores.composite`·`score` NULL, `data_quality.score_null_code = financial_profile`). 팩터 점수는 계산해 두지만 화면·API에 보이지 않는다. 대신 종목 화면의 매력도 칸과 홈 금융 탭이 **같은 하위 업종(주 테마) 안에서** 아래를 참고 정보로 보인다(`services/financial_profile.py`, `queries/financial_profile.sql`, API `attractiveness.financial_profile`·`GET /home/financial-peers`).

| 값 | 계산 | 비우는 경우 |
|---|---|---|
| P/B | 종가 / BPS | BPS ≤ 0 |
| ROE(3년 평균) | 지배주주 순이익 / 지배 자본의 최근 3개 FY 평균(최신 FY 결산일부터 1,000일 안) | 자본 ≤ 0인 해는 빼고, 남은 해가 없으면 비움 |
| P/E | 종가 / EPS | EPS ≤ 0 |

- **위치**: 'ROE 대비 P/B' 산점도에서 이 종목이 어디 있는지. P/B·ROE가 둘 다 있는 종목이 **8개 이상**이면 최소제곱 회귀선 P/B = a + b × ROE 대비 차이(`gap` = 실제 P/B − 회귀선 P/B, 음수면 "같은 ROE의 동종사보다 장부가 대비 싸게 거래됨"), **8개 미만**이면 중앙값 ROE·P/B 대비 위치만 보인다.
