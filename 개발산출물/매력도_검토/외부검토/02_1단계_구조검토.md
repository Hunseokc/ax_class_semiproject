# 1단계 — 구조와 핵심 공식 검토 (새 대화 B, 첨부A 함께)

```
첨부한 "매력도 모델 명세"는 개인 프로젝트 주식 분석 앱의 점수 모델이다. 너는 이 모델을 만든 사람이 아니라 외부 검토자다.

[앱의 목적 — 검토의 전제]
- 재무제표 숫자로 본 "같은 나라 비교 표본 안의 상대 위치"를 보여 주는 참고 점수다. 수익률 예측이나 매매 신호가 아니다.
- 대상은 국내·미국 약 600종목, 연간 재무(DART·SEC)와 일봉·시가총액만 쓴다. 미래 추정치는 쓰지 않는다.
- 그러니 "트레이딩 모델로서 부족하다"는 지적은 하지 말고, 이 목적 안에서 논리적으로 맞는지 봐라.

[요청 — 1단계는 이해 확인과 구조 검토만]
1. 계산 흐름을 목차 형태로 다시 정리하라(지표 → 정규화 → 중립화 → 팩터 → 합산 → 점수). 명세가 모호하거나 서로 맞지 않는 곳이 있으면 그 자리에 [모호] 표시를 하라.
2. 핵심 공식마다 "이 공식이 재려는 것"과 "실제로 재는 것"이 다를 수 있는 곳을 표로 적어라.
   열: 단계 | 공식 | 재려는 것 | 실제로 재는 것(다를 때만) | 근거
3. 이 단계에서는 개선안을 내지 마라. 한계 분석은 다음 질문에서 따로 요청한다.
4. 표 위주로, 항목당 2줄 이내로 답하라. 전체 15개 항목 이내.
```
