# 3단계 — 개선안과 검증 로직 (같은 대화 B, 첨부C 함께)

```
앞의 분석에서 '새로움' 또는 '부분적으로 알려짐'이면서 '논리 오류'인 문제만 대상으로, 구체적인 개선안과 그것을 검증할 로직을 제안하라. 첨부한 제약 안에서만 제안하라.

[규칙]
1. 개선안은 상위 5개만. 문제 하나에 개선안 하나(가장 좋은 것).
2. 개선안마다 반드시 적어라.
   - 바꿀 공식(전/후를 수식으로)
   - 필요한 데이터(첨부의 '쓸 수 있는 데이터' 안에서)
   - 근거: 참고할 연구·방법론(저자·연도). 확실하지 않으면 '확인 필요'
   - 검증 로직: 기준 스냅샷 S1·S2에서 무엇을 비교하는가(지표·표본·기준값)
   - **폐기 조건: 어떤 결과가 나오면 이 개선안을 버리는가** — 숫자로
   - 부작용: 이 변경으로 새로 나빠질 수 있는 것
3. 가중치를 데이터에 맞춰 최적화하는 제안은 하지 마라(과적합 — 첨부의 원칙 참고).
4. 표 하나 + 개선안별 3~5줄 설명으로 답하라.
```
