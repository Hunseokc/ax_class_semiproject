# 개선안의 제약 (3단계 첨부)

## 쓸 수 있는 데이터
- 국내 DART·미국 SEC 재무: 연간 FY 최근 5개, 분기 최근 20개(4분기는 연간 − 3분기 누적), 보고서 제출일
- 재무 계정: 매출, 영업이익, 지배주주 순이익, 총자산, 부채총계, 지배 자본, 영업현금흐름, 총포괄이익(지배), 지분법손익, 차입금·사채, 현금성자산, 영업권, 무형자산, 이자비용, 비지배지분 순이익
- 일봉(최근 약 2년, 수정주가), 시가총액, BPS·EPS·배당
- 테마(업종) 분류: 39개 테마, 종목당 주 테마 1개
- **없는 것**: 애널리스트 추정치를 점수에 쓰는 것(수집은 시작했지만 6개월 이상 쌓이기 전에는 점수에 쓰지 않음), 부문별 실적, 과거 시점 점수 이력(수익률 백테스트 불가)

## 검증 방법
- **기준 스냅샷 S1·S2**: 같은 코드로 2주 간격으로 뜬 배포 DB 덤프 두 개. 개선안은 두 날짜 모두에서 같은 결론일 때만 채택한다.
- **독립 기준(R10)**: 모델 지표에서 직접 계산되지 않는 기준으로 센 '상식적으로 이상한 상위 종목 수'(구조적 비영업 회사, 매출 2년 연속 감소, 최근 3년 영업적자 이력, 극단 변동성)와 '우량한데 순위가 낮은 종목 수'(3년 연속 흑자·매출 성장·높은 이익률·낮은 변동성인데 균형 하위 절반). 지금 합격선 이상 ≤ 16, 거짓 음성 ≤ 27(다시 잴 예정).
- **회귀 테스트**: 사람이 정한 반례 50여 개(예: 일회성 이익 회사가 가치 상위면 실패).
- **봉인 반례**: 점수를 보지 않은 쪽이 미리 쓴 반례 목록(최종 판정 때만 개봉).

## 원칙
- 가중치·임계값을 같은 데이터로 최적화하지 않는다. 합격선도 비교에 쓴 같은 데이터로 바꾸지 않는다.
- 근거 등급: A(연구 정의와 같음) / B(같은 개념·다른 산식, 차이 기록) / C(자체 선택). C 등급 제안은 민감도 측정을 함께 낸다.
- 점수는 같은 나라·같은 묶음 안 상대 순위다. 금융사는 종합 점수 대신 업종 안 P/B–ROE 비교를 보인다.
