## 1. 결론 먼저

| API | 판정 | 한 줄 근거 |
|---|---|---|
| `invest-opinion` 종목투자의견 | **사용 가능** | 실전·모의 도메인 모두 동작. 증권사별 의견·목표가 이력(2016년 이전까지), 1회 최대 100건 |
| `invest-opbysec` 증권사별 투자의견 | **사용 가능(단, `invest-opinion`과 같은 데이터)** | `FID_INPUT_ISCD`에 **종목코드**를 넣어야 결과가 나옴(회원사 코드는 0건). 같은 100건 + 현재가·종목명 필드 추가. 의견 필터(`FID_DIV_CLS_CODE`)는 분류가 틀려 쓰면 안 됨 |
| `estimate-perform` 종목추정실적 | **제한적** | **한국투자증권 애널리스트 1명의 추정**(시장 컨센서스 아님). 3개년 실적 + 2개년 추정. 표본 9종목 중 6종목만 값, **삼성전자·SK하이닉스는 반복 호출해도 빈 응답** |

- **앱키가 모의투자용이다.** 실전 도메인에서 `estimate-perform`·`invest-opbysec`는 `EGW02004 실전투자 도메인은 모의투자 앱키로 호출하실 수 없습니다.`(HTTP 500)로 거부되고, `invest-opinion`만 실전 도메인에서 통과한다. **모의 도메인(`https://openapivts.koreainvestment.com:29443`)에서는 3종 모두 `rt_cd=0`.** 토큰은 실전 도메인에서 발급된 기존 캐시 토큰(`backend/data/kis_token.json`)이 모의 도메인에서도 그대로 통했다(새로 발급하지 않음).
- 이 3종은 KIS 공식 Postman 샘플 중 **실전계좌 v2.6에만 있고 모의계좌 v1.6에는 없다**(`raw/R2/src/`). 즉 공식 지원은 실전이다. 모의 도메인 응답은 실전과 같은 데이터로 보이지만(아래 3-1), 언제든 막힐 수 있는 비공식 경로다 → R7 질문 목록: "실전 앱키 발급 여부".
- 호출 한도: 이 앱키로 0.25초 간격 호출 시 `EGW00201 초당 거래건수를 초과하였습니다.` 발생 → **초당 1건**(앱 `Throttle(1.05)`와 같음). 1.1초 간격으로는 오류 없음.

- 1회 최대 **100건**, 연속조회 키 없음 → `while len(rows)==100: 끝 날짜 = min(날짜) − 1일`로 이어 받는다(앱 `KisProvider._paged`와 같은 방식). 같은 날에 100건이 넘는 경우는 없다고 보고(하루 최대 관측 수 미측정), 같은 날·같은 증권사 중복은 표본에서 0건.

### 3-5. 판정

- **사용 가능.** 국내 "증권사별 최신 의견·목표가"(요청서 A·B)의 원천으로 충분하다. 증권사별 최신 1건 집계, 목표가 평균·중앙값·괴리율을 직접 계산할 수 있다.
- 두 API는 같은 데이터이므로 **수집은 `invest-opinion` 하나만** 쓴다(실전 도메인에서도 동작하는 유일한 것). `invest-opbysec`는 추가 정보가 현재가뿐이라 쓸 이유가 없다.
- 주의: 직전 의견 필드·구분 코드 사용 금지, 목표가 0 = 결측, 100건 페이징.

## 5. R3·R6에 넘길 것

- R3 국내 수집: **`invest-opinion` 하나만**, 도메인은 실전(현재 앱키로 동작 확인) — 막히면 모의 도메인으로 대체 가능(같은 데이터). 340종목 × (1 + 100건 초과 쪽 수). 1.1초 간격 → 1쪽당 약 1.1초, 340쪽이면 약 6.5분 + 추가 쪽. 빈 응답(`output: []`)은 "의견 없음"으로 집계(실패 아님), `EGW00201`은 재시도.
- 매핑표 입력 표기(현재까지): `BUY`, `매수`, `Buy`, `Strong BUY`, `MARKETPERFORM`, `Outperform`, `중립`, `Hold`, `NotRated`, `분석대상제외`. 대소문자·공백 차이를 정규화.
- R6: `invest-opbysec`로 "증권사별 날짜 범위 → 바뀐 종목만" 감지하는 경로는 **불가**(종목코드 입력만 동작). 변화 감지는 종목별 `invest-opinion`의 최근 N일 조회(1쪽)로 해야 한다. `estimate-perform`은 연속조회 없음·종목당 1회.
- R7 질문 후보: ① 실전 앱키 발급 여부(공식 지원 경로, `estimate-perform` 대형주 공백 확인) ② `estimate-perform`을 "한국투자증권 추정"으로라도 표시할지 ③ 포털 국내주식-187 응답 명세로 output3 추측 행 확정.
