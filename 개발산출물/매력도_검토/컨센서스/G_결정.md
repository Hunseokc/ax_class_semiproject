## 2. 확정 규칙 (C 단계가 그대로 구현)

### 2-1. 출처와 쓰지 않는 것

- 국내: KIS `invest-opbysec`(`FHKST663400C0`, 입력 `999` = 전 시장 피드)가 의견·목표가의 **유일한 수집·감지 경로**. KIS `estimate-perform`(`HHKST668300C0`)은 한국투자 새 의견이 피드에 온 종목만. `invest-opinion`은 쓰지 않는다(`invest-opbysec` 종목코드 입력과 결과가 같고 종목코드 필드가 없음).
- 미국: yfinance `upgrades_downgrades`·`get_recommendations()`·`analyst_price_targets`·`earnings_estimate`·`revenue_estimate`·`eps_trend`·`eps_revisions`·`get_earnings_dates` + 분할용 `Ticker.splits`.
- 쓰지 않음: 한경 컨센서스(차후 옵션), yfinance 국내 티커 값, `growth_estimates`, DART 잠정실적·SEC 8-K 트리거, 국내 시세 이상치 트리거.
- **점수에 넣지 않는다.** `score_*.sql`·`scoring.py`·`scoring.yaml`·`universe.yaml`·07:00 Job은 바꾸지 않는다(S1~S2 동안). 점수 편입 조건은 D-034 그대로(6개월 스냅샷·3곳 이상·변화 신호·M1 조건).

### 2-2. 정규화·집계 단위

- 표기는 소문자 + 공백·`-`·`_`·`.` 제거 키로 매수/중립/매도/미평가 4단계 매핑(국내 15·미국 48 표기, 매핑표는 `R3_의견데이터.md` 4절). KIS `invt_opnn_cls_code`·직전 의견 필드는 쓰지 않는다.
- 단위: 같은 종목·증권사의 **최신 1건**. 미평가(`NotRated`·`분석대상제외`)는 의견 수에서 뺀다.
- 목표가 0·0.0·`NotRated` = 결측(NULL). 최신 행이 미제시면 그 증권사는 목표가 집계에서 제외(옛 값으로 되돌아가지 않음).
- 분할 조정: 국내 = 발표 행 `stck_prdy_clpr`(원주가) ÷ `daily_prices.close`(발표일 직전 거래일), 미국 = `Ticker.splits` 누적비. 조정 전 미국 분할 의심(직전 대비 ≤0.55배·≥1.8배) 종목은 신호 보류.

### 2-3. 신호

| | 수준 | 변화 |
|---|---|---|
| 원천 | 6개월 증권사별 최신 1건 | 90일 창, 증권사별 "창 시작 직전 목표가 → 최신 목표가" 변화율(분할 조정) |
| 지표 | `(매수 + 4·m)/(n + 4)`, `m` = 그 시장 매수 비중 | 비교 가능 곳 변화율 중앙값 + 상향·하향 곳 수 |
| 신호 | 시장 안 하위 10% = 부정, 상위 10% = 긍정. **국내는 부정만** | 하위 10% + 중앙값 < 0 + 하향 > 상향 = 부정, 대칭 = 긍정(국내·미국 양쪽) |
| 최소 | 3곳 | 비교 가능 3곳 |
| 비교 묶음 | 같은 시장 전체 | 같은 시장 전체 |

- 의견 변화(4단계 이동)는 신호가 아니라 사실 문구(`90일 의견 하향 1곳`). 커버 중단은 신호로 쓰지 않는다.
- 신호는 시장 전체 백분위이므로 수집 Job 끝에 **DB만 읽는 배치로 매일 재계산**(외부 호출 0). 수집이 3일 넘게 멈추면 재계산하지 않는다(D-6).

### 2-4. 목표가 집계·컨센서스 지표

- 목표가: **3개월**, 증권사별 최신 1건, **중앙값** + 곳 수 + 범위, 최소 3곳. 괴리율 = 중앙값 / DB 최신 종가 − 1. 문구는 "상승 여력"이 아니라 `증권사 목표가 중앙값 대비`.
- 미국 지표: `earnings_estimate`·`revenue_estimate` `0y`·`+1y` `avg`(+ `numberOfAnalysts`, 3명 미만 숨김), `get_earnings_dates` 다음 일정·직전 서프라이즈.
- 국내 지표: 목표가 중앙값 + `estimate-perform` `2026.12E`·`2027.12E` 매출·영업이익·순이익·EPS(단위: 억원, EPS·PER·ROE 등은 ×10 저장값 — `R2_kis.md` 4절). 라벨은 1절 ②.
- 리비전 스냅샷(표시하지 않음): `eps_trend`·`earnings_estimate`·`revenue_estimate`·`eps_revisions`(미국) 주 1회 순환 + 실적 후 1~3일, `get_recommendations` `0m` 월 1회(20영업일 순환), `estimate-perform` 새 한국투자 의견 종목만. 바뀌지 않은 날은 새 행 없음.

### 2-5. 화면 (C6 API가 내줄 값의 기준)

- 종목 상세 매력도 점수 카드 **아래** 별도 카드 `애널리스트 (점수 미반영)`. 변화 줄 위, 수준 줄 아래. 방향어는 `하향 우세`/`상향 우세`만, 색·아이콘으로 좋고 나쁨을 칠하지 않음.
- 문구 초안: 변화 `애널리스트 · 목표가 하향 우세 — 90일: 하향 12곳 · 상향 0곳 · 중앙값 −39% (시장 −9%) · 10/28 기준` / 수준 `의견 · 6개월 증권사 17곳 중 매수 14 · 중립 3 — 매수 비중 시장 하위 10%` / 미달 `애널리스트 의견 적음 (6개월 2곳) · 10/28 기준` / 일괄 조정(시장 중앙값 ≤ −5%, 추측 임계) `최근 90일 시장 전체 목표가 중앙값 −9% (일괄 하향 구간)` / 출처 국내 `국내 증권사 25곳(KIS) 기준 · 외국계 제외`, 미국 `Yahoo Finance 기준`.
- 국내 금융 종목은 `금융 평균 매수 비중` 한 줄 병기. 목록 화면은 방향어가 있는 종목에만 작은 회색 칩. 도움말 한 줄 "매력도 점수는 재무·가격으로 계산하며 애널리스트 의견은 반영하지 않습니다".

### 2-6. 갱신·운영

- 국내: 매일 아침 `999` 피드로 **최근 3평일** 재조회(당일 피드 0건 → 다음 날 반영). 하루 100건 넘으면 `FID_DIV_CLS_CODE` 1·2·3 분할. 경계일 포함 이어 받기 + 중복 제거. 0.5초 간격 + `EGW00201` 재시도.
- 미국: 하루 **100종목** 예산, 선택 = `data_freshness`에서 `valid_until <= now()` 중 `priority DESC, valid_until ASC LIMIT 100`. 트리거: 실적 일정(우선 2), |일간 수익률| ≥ 5%(우선 3).
- 월 1회 전체 수집은 **20영업일 순환**으로 나눈다(한 번에 하면 Job 10분 초과).
- 새 Job `stockmind-consensus` 매일 **06:30 KST**, 약 5분. 순서 = 국내 피드 → 한국투자 추정 → 미국 예산·추정·일정·순환 → 분할 계수 → 신호 재계산. Scheduler 서비스 계정에 `run.invoker`. 06:05 refresh와 KIS 토큰 캐시 공유는 C3에서 확인.
- 초기 적재 ≈ 3,200회·≈ 39분 → **로컬에서 배포 DB로**(Job으로 돌리지 않음). 국내는 피드 12개월.
- 평상시 호출: 국내 ≈ 25회, 미국 ≈ 390회(계산식은 보고서 5-2).
- 요청 시 캐시: 1절 ③. 조회 API는 계속 DB만 읽는다.

### 2-7. 테이블 초안 (C1이 확정, 승인 먼저)

- `data_freshness` 재사용: kind 4개 추가(`consensus_opinions` 3영업일, `consensus_estimates` 7일, `consensus_dates` 다음 일정 + 1일, `kis_estimate` 90일) + 열 `priority smallint`·`reason text`.
- `consensus_feed_days`(신규): `feed_date` PK, `calls`, `rows`, `split_full`, `fetched_at`, `final`.
- 의견 이력(신규): `stock_id`, `source`(`KIS`/`YAHOO`), `firm`, `opinion_at`, `opinion_raw`·`opinion_norm`, `from_raw`·`action`·`price_target_action`(미국), `target_raw`·`prior_target_raw`(0 → NULL), `prev_close_raw`(국내), `adj_factor`·`target_adj`, `first_seen_at`·`fetched_at`.
- 스냅샷(신규): `(stock_id, source, kind, as_of)` + 값 + `fetched_at`.
- 신호(신규): `window_days`, `n_based`, `tp_med`, `tp_up`, `tp_down`, `market_med`, `pct`, `signal`, `computed_at`.
- 모든 행에 `fetched_at`. 화면에는 기준일을 작게.

### 2-8. sanity (C7)

- 점수 불변 S-1(의견 표 비움/채움 → `stock_scores` 같음), S-2(점수 코드가 컨센서스 테이블을 참조하지 않음, 정적 검사), S-3(기존 required 결과 C1~C8 전후 같음), S-4(`CONSENSUS-coverage`는 기록만, 실패 없음).
