# 매력도 모델 처방 재검토 요청 (레드팀 2차)

## 0. 너의 역할과 태도 — 가장 중요

너는 `개발산출물/10_매력도_모델_감사보고서.md`를 쓴 사람이 아니라, **그 보고서의 처방(6절)이 틀렸다는 것을 증명하러 온 2차 감사인**이다.

- 기본 가정은 "10번 보고서의 추천과 새 모델 뼈대도 잘못 설계됐다"이다. 반증 증거가 있을 때만 "문제없음"이라고 쓴다.
- **방어 금지.** "10번 보고서가 그렇게 결론냈다" / "공개 팩터 모델이 그렇게 한다" / "반례 수가 줄었다"는 그 자체로 근거가 되지 않는다. 10번 보고서도 **검토 대상**이다.
- 모든 주장은 **조회 결과 수치나 코드 줄 번호**로 뒷받침한다. 확인하지 못한 것은 "확인 못함"이라고 쓴다.
- "문제없음"이라고 판정하려면, 그 판정을 뒤집을 반례를 최소 1개 시도한 기록을 함께 남긴다.

## 1. 데이터와 재현

- 10번 보고서 0절과 **같은 방식, 같은 표본**을 쓴다: 배포 API를 GET으로만 읽은 660종목(as_of 2026-10-27), PR #111 기준 재계산.
- 10번에서 쓴 재계산 코드가 남아 있으면 재사용하고, 없으면 다시 만든 뒤 10번 보고서의 수치(예: SIRI 균형 4위, MU 가치 1위, 6절 시험판 순위표)를 먼저 재현해 차이를 적는다.
- **읽기 전용.** 프로젝트 코드·DB·설정은 고치지 않는다. 분석 스크립트는 임시 위치에서 실행하고 커밋하지 않는다.

## 2. 공격 관점 — 전부 데이터로 답할 것

### A. 처방 하나하나가 원인을 없애는가, 증상만 옮기는가

P1~P14 처방마다 "이 처방이 막으려던 문제가 새 지표에서 다른 모양으로 살아남는가"를 반례로 찾는다. 최소한 아래는 반드시 확인한다.

- **P1**: "2년 영업이익 변화 ÷ 2년 전 총자산"이 **영업적자 → 흑자 전환**을 여전히 큰 성장으로 세는가? 2년 전 영업적자였던 종목 중 새 성장 지표 상위 20%에 드는 종목 수와 예시.
- **P2**: 순이익 → 영업이익 전환 후에도 남는 왜곡(영업이익 안의 일회성, 지분법 이익이 영업이익에 들어가는 국내 지주·연결 구조)이 있는가? EV가 없는 지금 분모는 무엇을 쓰며 그게 P8 문제를 되살리는가?
- **P4**: "수익성 팩터 필수"가 정상적인 적자 성장 기업을 통째로 빼버리는가? 빠지는 종목 수와 목록.
- **P5**: min(최신, 3년 평균)이 **구조적으로 성장 중인 우량 기업**(꾸준히 이익이 느는 회사)을 체계적으로 깎는가?
- **P7**: 부채/자산으로 바꾸면 자본잠식 우량 기업(PM·MO·MCK 등)과 부실기업이 이제 구분되는가? 분포와 하단 몰림 다시 측정.
- **P13**: 빠진 팩터를 0으로 두면 재무가 없는 ADR·신규 상장 종목이 부당하게 깎이는가? 어느 쪽 오류가 더 큰지 수치로 비교.
- 나머지 처방도 같은 질문을 던진다.

### B. 새 모델 뼈대의 내부 일관성

- **성장성 방향**: 10번 보고서는 "매출 증가에 +를 주면 Fama-French 투자 팩터와 반대 방향"이라고 지적해 놓고 새 뼈대에서도 2년 매출 CAGR에 +를 준다. 둘 중 하나를 골라 근거와 함께 정한다(유지한다면 왜 이 앱에서는 +가 맞는지).
- **피오트로스키 신호 수(0~5 정수)**를 연속값 Z와 같은 팩터에 섞을 때 분포·동점 문제가 생기는가?
- **팩터 재표준화 후 합산**이 지표 수가 다른 팩터 사이의 실효 가중치 문제를 정말 해결하는가? 프리셋별 실효 가중치를 다시 잰다.
- 새 뼈대에서 지표 간 상관 행렬을 다시 계산해 **중복 계산**(P7·P12 같은 문제)이 새로 생기지 않았는지 본다.

### C. 평가 방법의 순환성 — 가장 중요

10번 보고서는 "이상한 종목 수 26 → 19"로 개선을 보였다. 그런데 "이상한 종목" 기준(일회성 = 순이익 ≫ 영업이익 등)과 처방(순이익 → 영업이익)이 같은 축이라 개선이 정의상 당연하게 나올 수 있다.

- 새 지표에서 **직접 계산되지 않는 독립 기준**으로 "이상한 종목"을 다시 정의한다. (예: 다년 매출 추세, 결산 시점, 비주식·연결 구조, 공시로 확인된 일회성 항목, 변동성 극단 등 — 어떤 기준을 왜 골랐는지 적는다.)
- 현재 모델 / 10번 시험판 / 이번에 수정한 안을 **같은 독립 기준**으로 비교한다.
- **거짓 양성만이 아니라 거짓 음성도 센다.** 처방 때문에 순위가 크게 떨어진 상식적 우량 종목(10번 7절의 "우량한데 점수 낮은" 조건 포함)이 몇 개 생겼는가?
- 처방 후 **새로 top10에 들어온 종목**을 전부 나열하고, 각각 상식에 맞는지 판정한다.

### D. 표시 방식

- **묶음 안 백분위(P3)**: 금융처럼 30개 묶음에서는 한 칸이 약 3.3점이라 작은 차이가 크게 보인다. 이 해상도 문제를 수치로 보이고, 가장 좋은 표시 방식 하나를 정한다.
- "같은 시장 상위 n%" + 경고 배지가 실제 화면에서 몇 %의 종목에 배지를 붙이게 되는지 센다(너무 많으면 배지가 의미를 잃는다).

### E. 실행 가능성과 순서

- 각 처방을 **지금 있는 필드로 가능 / 수집 필요**로 나누고, 수집이 필요하면 어떤 원천(API·공시)에서 무엇을 받아야 하는지 적는다.
- 처방 사이의 의존 관계(예: P8은 순차입금 수집 후)를 정리한다.
- 투자자 피해 감소량 대비 작업량으로 **실행 순서**를 정한다. 배포 점수가 코드와 다른 문제(P14)처럼 싸고 빠른 것은 앞에 둔다.

## 3. 진행 방식

1. 10번 보고서 수치 재현 → 차이 기록.
2. 2절 A~E를 차례로 공격하고, 깨지는 처방마다 반례를 붙인다.
3. 깨진 처방은 **고친 처방 하나**를 제안하고, 같은 독립 기준으로 다시 시험한다.
4. 판정: 처방마다 **유지 / 수정 / 폐기** 중 하나.

## 4. 결과물

`개발산출물/11_매력도_처방_감사보고서.md`로 쓴다.

1. **한 줄 판정**: 10번 처방 전체가 "그대로 진행 / 수정 후 진행 / 다시 설계" 중 무엇인지와 이유 한 줄
2. **처방별 판정표**: 번호 · 10번 처방 · 판정(유지/수정/폐기) · 근거(수치·반례) · 수정안
3. **새로 찾은 문제**: 처방이 만든 새 왜곡, 심각도(치명/높음/중간/낮음)
4. **수정된 모델 뼈대**: 팩터·지표·합산·표시 방식
5. **독립 기준 비교표**: 현재 / 10번 시험판 / 수정안 — 이상한 종목 수(거짓 양성), 떨어진 우량 종목 수(거짓 음성), 새로 top10에 든 종목
6. **"문제없음" 판정**: 처방 · 시도한 반례 · 왜 버텼는지
7. **작업 계획**: PR 단위 · 실행 순서 · 필요한 데이터 수집 · 바뀌는 파일
8. **확인 못한 것**

선택지를 늘어놓지 말고 각 항목에 가장 좋은 답 하나를 쓴다. 보고서를 다 쓰기 전에는 중간에 "진행할까요?"로 멈추지 말고 끝까지 간다.
