## 0. 준비 (2026-10-27)

- 이 PC(macOS)의 개발 DB `stockdb`는 Stage 1 상태(종목 25개, 일봉 2026-10-13, 테이블 10개)라 라운드 1~3이 쓴 개발 DB(2026-10-27, 비교 표본 661종목)가 아니다. 기존 DB는 그대로 두고 **새 DB `stockdb_fix3`**에 실데이터를 적재한다: `init-db` → `master` → `listing` → 미국 시가총액 순위 → `fx/indices/prices --full` → 노출 종목 재무·밸류에이션 → `benchmark --reselect`(업종 코드·선정·평시 데이터) → 비교군 재무 3년 → `scores` → `sanity`(v2.2 기준선).
- 명령은 `docker compose -f compose.yml -f compose.dev.yml run --rm -T -e DATABASE_URL=postgresql+psycopg://stock:stock@db:5432/stockdb_fix3 api …`로 실행한다(compose의 DATABASE_URL만 바꿈).
- 그래서 수치는 라운드 3 보고서와 조금 다를 수 있다(비교군을 오늘 시가총액으로 다시 골랐고 데이터 기준일이 다름). 수정 3의 전·후 비교는 모두 이 DB의 v2.2 기준선과 한다.
