### 8 — S1 덤프 (D-041)
1. `gcloud run jobs executions list --job stockmind-benchmark $P --limit 1` 로 07:00 실행이 **성공 완료**인지 본다(07:40 전).
2. 배포 DB 접속 정보는 `ax_stockmind/.env`의 `SUPABASE_DB_HOST·PORT·NAME·USER·PASSWORD`(세션 풀러). 서버 버전에 맞는 `pg_dump`를 쓴다:
   ```bash
   set -a; . ./.env; set +a
   docker run --rm -e PGPASSWORD="$SUPABASE_DB_PASSWORD" postgres:17 psql -h "$SUPABASE_DB_HOST" -p "$SUPABASE_DB_PORT" -U "$SUPABASE_DB_USER" -d "$SUPABASE_DB_NAME" -Atc "SHOW server_version; SELECT MAX(as_of) FROM stock_scores;"
   # 주 버전이 17이 아니면 이미지 태그를 서버 주 버전에 맞춘다
   NAME=S1_deploy_$(date +%Y%m%d_%H%M).dump
   docker run --rm -v "$PWD/../snapshots:/out" -e PGPASSWORD="$SUPABASE_DB_PASSWORD" postgres:17 pg_dump -Fc -n public -h "$SUPABASE_DB_HOST" -p "$SUPABASE_DB_PORT" -U "$SUPABASE_DB_USER" -d "$SUPABASE_DB_NAME" -f /out/$NAME
   shasum -a 256 ../snapshots/$NAME
   ```
   - 덤프는 레포 밖(`../snapshots/`)에 둔다(개인 데이터·용량). 비밀번호는 출력하지 않는다.
3. 기록할 것: 덤프 이름 · sha256 · 덤프 시각(KST) · `as_of` · 07:00 실행 이름.
