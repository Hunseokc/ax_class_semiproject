# 09. 매력도 점수 정의서 (다중 팩터 모델)

> 매력도는 **유니버스(25종목) 안에서 같은 시장끼리 비교한 상대적 위치를 나타내는 팩터 점수**이며, 수익률 예측이나 투자 권유가 아니다. 화면(종목 상세·주식 리스트 하단)과 API 응답(`disclaimer`)에 같은 문구를 표시한다.

- 구현: `app/services/scoring.py`(흐름·검증), `app/queries/score_*.sql`(계산), `config/scoring.yaml`(프리셋·축소 계수)
- 실행: `python -m app.ingest scores`, `POST /api/v1/market/refresh`(SCORES 작업). 같은 `as_of`는 한 트랜잭션에서 DELETE 후 INSERT
- 검증: `tests/test_scoring.py` (07 결과서 SC-01~15)

|---|---|---|---|

## 2. 지표 정의와 NULL 사유

기준(as_of): 종목별 최신 거래일 종가, 최신 밸류에이션 스냅샷, 최신 FY 재무(직전 FY는 결산일 간격 330~400일일 때만 인정).

| 팩터 | 지표(`metric`) | 계산 | 방향 | NULL·대체 사유 |
|---|---|---|---|---|
| value | 이익수익률 E/P (`earnings_yield`) | EPS / 종가 | + | EPS·순이익 또는 종가 없음. **EPS 미제공이면 FY 순이익 / 주식수로 대체**(KRX는 적자 기업 EPS를 주지 않음 → 적자는 음수 E/P로 하위) |
| value | B/P (`book_yield`) | BPS / 종가 | + | BPS 또는 종가 없음 |
| quality | ROE (`roe`) | 순이익 / 자본 | + | 재무 없음, 자본 ≤ 0 |
| quality | 영업이익률 (`operating_margin`) | 영업이익 / 매출 | + | 재무 없음, 매출 0 |
| growth | 매출 YoY (`revenue_yoy`) | 매출_t / 매출_{t−1} − 1 | + | 직전 FY 없음, 직전 매출 ≤ 0 |
| growth | EPS 변화/주가 (`eps_change_yield`) | (EPS_t − EPS_{t−1}) / 종가. EPS = FY 순이익 / 최신 주식수 | + | 직전 FY 없음, 주식수 없음. 두 해 모두 최신 주식수를 써서 주식수 변동은 반영하지 않음 |
| safety | 부채비율 (`debt_ratio`) | 총부채 / 자본 | − | 재무 없음. **자본 ≤ 0이면 원값 NULL, Z = −3 고정** |
| safety | 변동성 (`volatility`) | 최근 252거래일 일수익률 STDDEV_SAMP × √252 | − | 일봉 253개 미만 |
| momentum | 12-1개월 수익률 (`momentum`) | 종가(t−21거래일) / 종가(t−252거래일) − 1 | + | 일봉 127개 미만. **253개 미만이면 6-1개월(t−21 / t−126)로 대체** |

- 주식수 = 상장주식수, 없으면 시가총액 / 종가.
- PER·PBR 값은 직접 점수화하지 않는다(음수 PER 왜곡 방지). 화면의 핵심 지표에는 그대로 표시한다.
- 계산 불가 지표와 사유, 대체 계산은 `stock_scores.data_quality`(`missing_metrics`, `notes`)에 기록하고 상세 화면에 보여 준다.

## 3. 정규화 (비교군 = 같은 country)

- 지표별 중앙값 m과 MAD = median(|x − m|)으로 **로버스트 Z = (x − m) / (1.4826 × MAD)**.
- 유효 표본이 5개 미만이거나 MAD = 0이면 평균·표본표준편차 Z로 대체하고, 표준편차도 0이거나 표본이 1개면 Z = 0.
- 방향이 −인 지표(부채비율·변동성)는 부호를 뒤집고, 모든 Z를 **[−3, 3]**으로 자른다(LEAST/GREATEST).
- 중앙값·MAD는 `PERCENTILE_CONT(0.5) WITHIN GROUP` CTE로, Z는 JOIN으로 계산한다.
- 1.4826은 정규분포에서 MAD를 표준편차와 같은 척도로 맞추는 상수다. 국내 16·미국 9종목의 작은 표본에서 극단값 하나가 평균·표준편차를 크게 흔들지 않도록 중앙값·MAD를 쓴다.

## 4. 섹터 중립화 (축소 추정)

- `peer_group_members.is_primary`로 종목별 **주 그룹**을 하나 지정한다(부분 UNIQUE 인덱스 `ux_pgm_primary`로 종목당 1개 보장). master 적재 시 `config/universe.yaml`에서 종목이 처음 나오는 그룹이 주 그룹이다.
- **z_adj = z − (n / (n + k)) × 같은 국가·같은 주 그룹 내 z 평균**. n은 같은 국가의 주 그룹 구성원 중 그 지표의 z가 있는 종목 수, k = `shrinkage_k`(기본 5).
- **그룹 평균에는 자기 자신이 포함된다.** 그래서 그룹이 작을수록(n이 작을수록) 평균을 덜 빼도록 n/(n+k)로 축소한다.
- 주 그룹이 없거나 n = 1이면 z_adj = z. z_adj는 다시 자르지 않는다.
- 주 그룹에는 국내·해외 종목이 함께 있지만(예: 반도체), z는 국가 안에서 표준화한 값이라 **그룹 평균은 같은 국가 구성원끼리만** 낸다(2026-10-07 변경). 이전에는 국가를 섞어, 국내 시장에서 저평가인 현대차·기아 때문에 Tesla의 가치 Z가 −0.94 → −1.58로 더 깎였다.
- 자본 ≤ 0으로 Z = −3 고정인 부채비율도 다른 z와 같이 중립화에 참여한다.

## 5. 합산과 0~100 변환

- 팩터 점수 F = 해당 팩터의 유효 지표 z_adj 평균(지표 1개 이상).
- 종합 = Σ(w_f × F_f) / Σ w_f — **유효 팩터만으로 가중치를 재정규화**한다. 유효 팩터가 **3개 미만이면 점수는 NULL**이고 사유를 `data_quality.score_null_reason`에 기록한다. `factor_coverage`는 유효 팩터 수(0~5)다.
- 종합 점수를 같은 country·프리셋 안에서 평균·표본표준편차로 다시 표준화한 Z_c를 구하고 **Final = 100 × Φ(Z_c)**, Φ(z) = 0.5 × (1 + erf(z / √2)). 표준편차가 0이면 Z_c = 0(50점).
- **PostgreSQL 16의 erf 지원 확인**: 운영 DB(PostgreSQL 16.15)에서 `erf(1/sqrt(2))` = 0.6827, Φ(1) = 0.8413을 확인해 SQL 안에서 변환한다(Python `math.erf` 대체 불필요).
- 팩터 기여도(API·화면) = 유효 팩터만으로 재정규화한 가중치 × F. 기여도 합 = 종합.

### Min-Max를 쓰지 않는 이유
Min-Max(= (x − 최소) / (최대 − 최소) × 100)는 **최고 종목이 항상 100, 최저 종목이 항상 0**이 되어 실제 차이가 작아도 극단 점수가 생기고, 종목 하나가 추가·삭제되면 최고·최저가 바뀌어 **다른 모든 종목의 점수가 함께 흔들린다**. Φ 변환은 평균에서 몇 표준편차 떨어졌는지를 확률 척도로 바꾸므로 0·100에 도달하지 않고, 종목이 추가되어도 기존 종목 점수가 0·100으로 재배치되지 않는다(테스트 SC-09).

## 6. 가중치 프리셋 (`scoring_presets`·`scoring_weights`)

화면 이름은 "투자 성향"이며 `sort_order` 순서(위험 → 성장 → 균형 → 가치)로 보여 준다.

| 순서 | 프리셋 | 설명 | value | quality | growth | safety | momentum |
|---|---|---|---|---|---|---|---|
| 1 | aggressive (위험) | 모멘텀·성장 중심 — 하이리스크·하이리턴 성향 | 0.05 | 0.10 | 0.35 | 0.10 | 0.40 |
| 2 | growth (성장) | 성장성 중심 | 0.10 | 0.20 | 0.40 | 0.05 | 0.25 |
| 3 | balanced (균형, 기본) | 5개 팩터 균등 | 0.20 | 0.20 | 0.20 | 0.20 | 0.20 |
| 4 | value (가치) | 저평가·안정성 중심 | 0.40 | 0.20 | 0.10 | 0.20 | 0.10 |

- 2026-10-07 개편: 이름이 직관적이지 않던 quality(퀄리티형)를 없애고 aggressive(위험)를 추가했다. `db/migrations/002_presets.sql`(멱등)이 quality 점수·프리셋을 지우고 4개를 맞추며, `config/scoring.yaml`에서 빠진 프리셋은 적재 시 점수와 함께 삭제된다. 화면에 저장된 옛 값 quality는 balanced로 바뀐다.

- 공개된 일반적 투자 스타일을 단순화한 가중치이며 **특정 인물의 판단이 아니다**(화면·`GET /scoring/presets`의 `note`).
- 프리셋별 가중치 합 = 1은 행 간 제약이라 CHECK로 걸 수 없다. `config/scoring.yaml`을 DB에 적재할 때(`init-db`, `migrate`, `scores`) 팩터 5개·0~1·소수점 셋째 자리·합 = 1을 검증하고, 테스트(SC-10·11)로 보장한다.
- 대시보드·주식 리스트·종목 상세의 "투자 성향" 펼침 메뉴에서 고르며, 리스트·홈 관심종목 카드·종목 상세가 `?preset=` 점수를 보여 준다(기본 balanced). 선택은 브라우저 저장값과 URL `?preset=`에 남고, 관심종목 카드를 누르면 상세가 같은 성향으로 열린다. 경쟁 비교 표와 포트폴리오 가중평균 매력도는 균형 프리셋 기준이다.

## 7. 현재 데이터 결과 (2026-10-07, 균형, 비교군 포함)

비교 표본 146종목(국내 70 = 노출 16 + 비교군 54, 미국 76 = 노출 9 + 비교군 67) 모두 유효 팩터 5/5. 점수 범위 국내 0.22~98.38, 미국 0.02~95.65.
- 노출 종목 상위: SK하이닉스(98.38). 하위권 극단값은 적자 바이오(HLB·리가켐바이오)와 적자 전기차·배터리(EOSE·Lucid) — 수치가 실제로 나쁜 종목이다.
- Tesla: 비교군 확대 전 2.40점(미국 9개 중 꼴찌) → 28.69점(미국 76개 중 62위). PER 약 350배, 매출 감소, 낮은 이익률은 그대로라 여전히 하위권이다.
- 주의: 미국 2차전지 그룹은 적자 소형주가 많아 그룹 평균이 크게 낮다. 섹터 중립화가 그 평균을 빼므로, 그룹 안에서 상대적으로 나은 Albemarle(적자 폭 축소로 EPS 변화 +3, PBR 1.56)이 미국 1위(95.65)가 된다. "업종 안에서의 상대 위치"를 반영한 설계상 결과이며, 후보 풀 구성에 따라 달라진다(9절).

## 8. 한계

- 비교 표본(국가별 70·76종목) 안의 상대 위치다. 후보 풀과 시가총액 순위가 바뀌면 점수의 의미도 바뀐다.
- 재무는 최신 FY 1개년 기준이며 분기 실적·전망치는 쓰지 않는다. KR(K-IFRS 연결)과 US(US-GAAP) 회계기준 차이는 국가별 정규화로 비교를 분리해 완화할 뿐 없애지 못한다.
- EPS 변화는 FY 순이익을 최신 주식수로 나눈 값이라 증자·자사주 소각에 따른 주식수 변화를 반영하지 않는다.
- KRX가 제공하는 EPS와 DART 순이익 기반 EPS는 산정 기준이 다를 수 있다(ASSUMPTIONS A-38). EPS 미제공 종목만 대체 계산을 쓴다.

## 9. 비교 표본: 노출 종목 + 매력도 비교군 (2026-10-07)

화면에 보여 주는 25종목만으로는 국가별 표본이 9~16개라, 꼴찌 종목이 0점 근처로 쏠렸다. 점수 계산에는 섹터별 비교군을 함께 쓴다.

| 항목 | 노출 종목(featured, 25) | 매력도 비교군(benchmark, 121) |
|---|---|---|
| 정하는 방법 | `config/universe.yaml` stocks | 국가·섹터마다 노출 종목 + 후보(benchmark_candidates) 중 **시가총액 상위 (10 − 노출 종목 수)**개. 30일마다 다시 고름 |
| 갱신 | 4시간(REFRESH_TTL_HOURS) — 앱 안 스케줄러 또는 사이드바 새로고침 | **1일 1회**(매일 07:00 KST 이후) |
| 평시 저장 데이터 | 일봉 2년, 일별 밸류에이션 1년, FY 5개년, 공시 1년 | 일봉 400일, 최신 밸류에이션, FY 3개년(새 결산기가 나왔을 법할 때만 확인) |
| 상세 데이터 | 항상 | 상세 화면을 열거나 관심종목에 담을 때 공시·2년 일봉·5개년 재무를 받음(24시간 재사용). 30일 넘게 안 열면 평시 데이터만 남김 |
| 화면 | 기본 목록·경쟁 비교 표·통계 | 검색할 때만 목록에 나옴(배지 "비교군"). 경쟁 비교 표에는 넣지 않음 |

- 섹터 정의(2차전지·방산·빅테크 등)가 KRX 업종·GICS와 1:1로 맞지 않아 **후보 풀은 직접 정하고, 선정은 적재 시점 실제 시가총액으로 자동**으로 한다. 금융 섹터는 매출·영업이익 구조가 달라 넣지 않는다.
- 시가총액을 못 받은 후보는 빠진다(2026-10-07: 012510 더존비즈온).
- 관심종목·포트폴리오에 담긴 비교군 종목은 4시간 갱신 대상이 되고, 비교군에서 빠져도 비활성화하지 않는다.
- DART는 분당 100회 이상 호출하면 이용이 제한될 수 있어, 프로세스 안에서 60초 90회 창 제한을 두고 재무·공시 작업은 DB 잠금으로 한 번에 하나만 돈다. 첫 적재(선정 + 121종목) 실측 494초, 실패 0건.
