## 1. 결론 요약

1. 이전 결론("무료 API로 컨센서스 수집은 어렵다")은 **절반만 맞다.** 미국은 yfinance로 애널리스트 수가 붙은 시장 컨센서스(EPS·매출·목표가·월별 의견)를 얻는다. 국내 시장 컨센서스(여러 증권사 평균 추정치)는 무료로 얻지 못한다. KIS `estimate-perform`은 **한국투자증권 애널리스트 1명의 추정**이다.
2. 국내 애널리스트 의견은 **KIS `invest-opbysec`로 충분하다.** 국내 25개 증권사의 의견·목표가 이력을 주고, `999` 피드 하루 1~4회 호출로 전 시장의 새 의견을 모두 받는다(종목별 수집과 1,194건 완전 일치).
3. 컨센서스 지표: 미국 = yfinance `earnings_estimate`·`revenue_estimate`·`analyst_price_targets`(+ 직접 집계 목표가 중앙값). 국내 = 목표가 중앙값(직접 집계) + "한국투자증권 추정" 라벨의 `estimate-perform` 2개 연도(대형주 2종목 공백).
4. 의견 신호: **수준** = 6개월 증권사별 최신 1건의 베이지안 축소 매수 비율, 시장 안 하위/상위 10%(국내는 부정 쪽만). **변화** = 90일 목표가 변화 중앙값, 시장 안 하위/상위 10%(국내·미국 양쪽). 최소 3곳. 두 줄로 따로 보이고 변화 줄을 위에 둔다.
5. 문장형 데이터는 무료 API에 없다 → AI API 검토 대상이 없다. 운영은 새 Job 1개(매일 06:30, 약 5분), 평상시 하루 호출 국내 ≈ 25회·미국 ≈ 390회.

약관 요지(R0 5절): Yahoo 약관은 자동 수집(2(d)(9))·상업 이용(2(e))·재배포(2(h))를 금지한다. yfinance README는 개인·연구 용도라고 밝힌다. KIS는 "외부 고객에게 서비스를 제공하려는 법인은 제휴 대상"이라고 안내한다(포털 제휴 안내). KIS 이용약관 본문은 **미확인**이다(포털 JS 팝업이라 자동으로 열지 못함). → 과제 발표·데모(비상업, 소수)에서는 출처를 표시하고 쓴다. 공개 서비스로 열려면 두 소스 모두 별도 계약·제휴가 필요하다.

호출 제한(R2·R3·R6): KIS 실전 앱키는 0.5초 간격에서도 `EGW00201`(초당 한도)이 4~6% 나서 재시도로 해결했다. 공식 한도는 미확인이다. yfinance는 비교군 1,688회(0.5초 간격) 동안 차단이 없었다. 클라우드(Cloud Run) 환경에서 yfinance가 차단되는지는 시험하지 않았다(미확인, 기존 시세 보완도 같은 위험).

## 3. 애널리스트 의견 유형 분류

| 유형 | 해당 소스 | 활용 |
|---|---|---|
| A. 카운트형 | yfinance `get_recommendations()` | 4개월·날짜 없음이라 신호 원천으로는 쓰지 않는다. 월 1회 스냅샷으로 쌓고 직접 집계와 대조하는 용도(3-1) |
| B. 이력형 | KIS `invest-opbysec`(= `invest-opinion`), yfinance `upgrades_downgrades` | 수준·변화 신호의 원천(3-1·3-2), 목표가 직접 집계(3-3) |
| C. 문장형 | **없음** | 무료 API 범위에서 문장형 없음(3-4) |

### 3-1. A·B 공통 — 기준 데이터 정의 (요청서 A-1)

- **집계 단위**: 증권사별 최신 1건(같은 종목·증권사에서 날짜가 가장 늦은 행). 같은 날 같은 증권사·종목 중복은 국내·미국 모두 0건이라 동점 규칙은 필요 없다(R3 2절).
- **정규화**: 소문자로 바꾸고 공백·`-`·`_`·`.`을 지운 키로 매수/중립/매도/미평가 4단계에 매핑한다. 비교군 12개월에서 미분류 0건이다(R3 4절).
  - 국내 15종: 매수 `BUY`·`매수`·`Buy`·`Trading BUY`(애매: 단기 매수)·`Outperform`·`Strong BUY` / 중립 `Hold`·`HOLD`·`중립`·`Marketperform`·`MARKETPERFORM`·`Neutral` / 매도 `매도`·`Underperform` / 미평가 `NotRated`(+ 표본의 `분석대상제외`)
  - 미국 48종: 매수 17(`Buy`·`Overweight`·`Outperform` 등, 애매 `Positive`·`Accumulate`·`Outperformer`·`Add` 등), 중립 16(`Neutral`·`Equal-Weight`·`Hold`·`Market Perform` 등, 애매 `Peer Perform`·`Sector Weight`·`Mixed` 등), 매도 11(`Underweight`·`Underperform`·`Sell` 등, 애매 `Trim`). 12개월 최신 행 중 애매 표기는 200건 안팎이라 분류를 바꿔도 결과 영향은 작다.
  - KIS `invt_opnn_cls_code`는 `BUY`·`매수`만 2이고 `Buy`·`Hold`·`NotRated`는 전부 3이다 → **코드·필터를 분류에 쓰지 않고 텍스트로 분류한다.**
- **미평가**: 의견 수에서 뺀다. 국내 최신 1건의 10.3%가 `NotRated`(전부 목표가 없음)다. 비매수로 세면 신호의 12.4%가 바뀐다(R4 5-3절).
- **소스 일치(미국)**: `get_recommendations` `0m`과 직접 집계(12개월 최신 1건)의 매수 비율은 315종목에서 피어슨 0.905, 차 절대값 중앙값 0.054다. 직접 집계 인원은 월별의 약 2/3이다. 직접 집계는 날짜·증권사·목표가가 있어 기간 비교와 시점 재구성이 된다 → **신호 계산 기준은 직접 집계**로 한다(R3 6절).

### 3-2. A·B → 의견 신호 규칙 초안 (상세는 4-2)

| | 수준 신호 | 변화 신호 |
|---|---|---|
| 원천 | 6개월 증권사별 최신 1건, 미평가 제외 | 90일 창, 증권사별 "창 시작 직전 목표가 → 최신 목표가" 변화율(분할 조정) |
| 지표 | 베이지안 축소 매수 비율 `(매수 + k·m)/(n + k)`, `m` = 시장 매수 비중, `k` = 적률 추정(국내 3.78·미국 3.32) | 비교 가능 곳 변화율의 중앙값 + 상향·하향 곳 수 |
| 신호 | 시장 안 백분위 하위 10% = 부정, 상위 10% = 긍정(**국내는 부정만**) | 하위 10% + 중앙값 < 0 + 하향 > 상향 = 부정, 대칭 = 긍정(국내·미국 양쪽) |
| 최소 건수 | 3곳 | 비교 가능 3곳 |
| 현재 결과 | 국내 부정 20/201, 미국 부정 29·긍정 30/293 | 국내 부정 15·긍정 15/157, 미국 부정 26·긍정 27/262 |

### 3-3. B → 목표가 컨센서스 직접 집계 (요청서 B)

| 항목 | 규칙 | 근거(R5 5절) |
|---|---|---|
| 기간 | **3개월** | 6개월이면 목표가 1/3이 90일 넘게 묵고, 국내는 7월부터의 일괄 하향 전 값이 섞임. 통과 손실 국내 −16·미국 −10종목 |
| 단위 | 증권사별 최신 1건 | 의견과 같은 규칙 |
| 대표값 | **중앙값** + 곳 수 + 범위 | 평균과 차 대부분 2% 안이지만 꼬리 있음(MRNA 평균 106 vs 중앙값 90). Yahoo `median`과 차 중앙값 1.7% |
| 미제시 | 최신 행이 `NotRated`·목표가 0·0.0이면 그 증권사 **제외**(옛 목표가로 되돌아가지 않음) | 국내 3개월 1,749건 중 119, 미국 2,818건 중 65 |
| 최소 | 3곳 | 통과 국내 185·미국 282종목 |
| 분할 | 조정 필수 | 국내 22종목 미조정(나이스정보통신 1:5 등), 미국 APH·CRWD 등 |
| 괴리율 | 중앙값 / **DB 최신 종가** − 1 | KIS `dprt`(발표 전일 종가 기준)와 차 중앙값 17%p |
| 상향·하향 건수 | 만들 수 있음(변화 신호의 90일 상향·하향 곳 수) | |

- 국내 괴리율 중앙값 57%, 185종목 중 173종목이 현재가 < 최저 목표가다. KIS 응답 자체도 같다(삼성전자 목표가 500,000 vs 현재가 230,500, `dprt` −53.9). 주가 하락·목표가 일괄 하향 구간과 국내 목표가의 구조적 낙관이 겹친 값이다(자본시장연구원 26-06: 내재 수익률 평균 33.9% vs 실현 약 4%). → 화면에서는 "상승 여력"이 아니라 "증권사 목표가 중앙값 대비"로만 적는다.

### 3-4. C 문장형 → AI API

- KIS 3종과 yfinance 8종의 응답 필드를 전부 확인했다. 리포트 제목·코멘트·요약 필드는 없고, 국내는 애널리스트 이름도 없다(`estimate-perform`의 `name1` 제외) → **무료 API 범위에서 문장형 없음.**
- 후보(구현 안 함): 국내 포털 리서치 리포트 목록(제목·증권사·날짜)은 크롤링이 필요하고 약관은 미확인이다. 미국 yfinance `news`는 이번 검토 범위 밖이라 미확인이다.
- AI API: 입력이 없으므로 **해당 없음.** 나중에 리포트 제목이 생겨도 제목이 짧으므로("목표가 하향", "실적 부진") **키워드 규칙을 먼저** 권한다.

## 4. 화면 표시와 스냅샷 제안

### 4-1. 컨센서스 지표 (점수 미반영, 지표 목록에 나열)

| 시장 | 필드 | 라벨(초안) | 값이 없을 때 |
|---|---|---|---|
| 미국 | `earnings_estimate` `0y`·`+1y` `avg`(+ `numberOfAnalysts`) | `EPS 추정 (FY2026, 41명)` | 애널리스트 3명 미만이면 숨김(분기는 1명까지 떨어짐) |
| 미국 | `revenue_estimate` `0y`·`+1y` `avg` | `매출 추정 (FY2026, 38명)` | 같음 |
| 미국 | `get_earnings_dates` 다음 일정·직전 서프라이즈 | `다음 실적 11/02 · 직전 서프라이즈 +6.7%` | 일정 없음(79/321종목)이면 숨김 |
| 미국·국내 | 목표가 중앙값(3-3) | `목표가 중앙값 $315 (21곳, $180~$515) · 현재가 대비 +46%` | 3곳 미만이면 `목표가 적음 (N곳)` |
| 국내 | `estimate-perform` `2026.12E`·`2027.12E` 매출·영업이익·순이익·EPS | **`한국투자증권 추정 (애널리스트 OOO, 10/07)`** — "컨센서스" 표현 금지 | 빈 응답(삼성전자·SK하이닉스 포함)이면 행 자체를 숨김 |

- 국내·미국 입력 성격이 다르다(미국 = 수십 명 컨센서스, 국내 = 한 증권사 추정). 그래서 라벨에 출처와 인원을 항상 적는다. 국내 행에 "컨센서스"라는 단어를 쓰지 않는다.
- 쓰지 않는 것: `growth_estimates`(업종 비교 불가, `earnings_estimate.growth`와 중복), 국내 티커 yfinance 값(`005930.KS`는 추정치가 나오지만 KIS와 섞지 않는다 — 6-1 질문 ④), `eps_revisions`(표시 안 함).

### 4-2. 리비전 스냅샷 (표시하지 않고 쌓기만)

| 소스 | 저장 필드 | 주기 |
|---|---|---|
| yfinance `eps_trend` | 기간별 `current`(+ 받은 날의 `7/30/60/90daysAgo`) | 주 1회 순환 + 실적 후 1~3일 |
| yfinance `earnings_estimate`·`revenue_estimate` | 기간별 `avg`·`low`·`high`·`numberOfAnalysts` | 같음 |
| yfinance `eps_revisions`(미국만) | 4개 값 | 같음 |
| yfinance `get_recommendations` | `0m` 5개 카운트 | 월 1회(20영업일 순환) |
| KIS `estimate-perform` | `estdate`·`rcmd_name`·추정 2개 연도 전 행 | 피드에 새 한국투자 의견이 온 종목만 |

- `eps_trend`가 90일 과거값을 내장하므로 최근 90일 리비전은 스냅샷 없이도 계산할 수 있다. 그보다 긴 이력만 쌓인 스냅샷으로 만든다. 바뀌지 않은 날은 새 행을 만들지 않는다(**추측**: 저장량 절약).

### 4-3. 애널리스트 의견 신호 — 검토 결과 (요청서 A-2~A-5)

#### 채택 방식과 임계값 (A-2, R4)

| 항목 | 채택 | 분포상 위치·이유 |
|---|---|---|
| 방식 | (라) 베이지안 축소 매수 비율의 시장 안 백분위 | 의견 2건과 30건을 같은 저울에 올리지 않음 — 미국 긍정 종목 의견 수 중앙값 (가) 8 → (라) 15 |
| 기간 | 6개월 | 최소 3건 통과 국내 201·미국 293(12개월 대비 −18·−11). 최신 1건 나이 중앙값 국내 91 → 77일 |
| 국내 임계 | **부정만**: 축소값 하위 10%(현재 ≤ 0.886, 중앙값 0.987) → 20종목 | 국내 매수 비율 p25·p50·p75·p90이 전부 1.0. 긍정을 두면 "매수 100% + 의견 18곳 이상" = 커버 수 신호가 됨 |
| 미국 임계 | 부정 하위 10%(≤ 0.374) 29종목, 긍정 상위 10%(≥ 0.892) 30종목 | 매수 비율이 0.27(p10)~1.0(p90)에 퍼짐 |
| 10%의 근거 | 측정값 + 판단(**추측** 성분) | 20%로 넓히면 국내 추가 19종목 중 18종목이 비매수 1건뿐, 미국은 40% 종목에 신호 |
| 안정성 | 한 달 전 대비 부정↔긍정 직접 전환 0. 부정 쪽 변동 국내 2.0%·미국 4.5% | |
| 시총·의견 수 | 국내 부정은 시총 5분위마다 2~5종목(쏠림 없음). 미국 부정은 소형 쪽(Q5 11 vs Q1 2) — 지표 자체가 대형주일수록 매수 비율이 높아 생긴 실제 차이로 보고 보정하지 않음 | |
| 비교 묶음 | 같은 시장 전체 | 테마가 매수 비율 차이의 6~9%만 설명, 테마별 14~42종목이라 10%가 1~4종목 |

탈락: (가) 매수 비율 백분위는 의견 적은 종목이 양 끝을 차지하고 국내 긍정이 동점으로 불가했다. (나) 비매수 존재·건수는 미국 89% 종목에 신호가 붙고, 국내 ≥2건은 대형주 쏠림(부정 순위 중앙값 64 vs 전체 112)이었다. (다) 의견 점수는 (가)와 사실상 같았다. 목표가 괴리율 백분위(참고)는 한 달 변동 9.7~13%로 가장 불안정해 3-3 표시로 넘겼다. 12개월·3개월 창과 테마 안 비교도 탈락했다(R4 8절).

대표 종목(6개월): 삼성전자·SK하이닉스 22/0/0(신호 없음), 카카오 16/2/0(축소값 0.902, 경계 바로 위 — 신호 없음), 국내 부정 상위 SK아이이테크놀로지 3/6/0·제주항공 2/5/0·HMM 5/5/0. 미국 NVDA 29/0/0·MSFT 28/0/0 긍정, AAPL 16/8/3 신호 없음, CLX 0/7/3·PYPL 3/18/3 부정. 국내 부정 20종목 중 **금융이 7종목**이다(업종 자체에 중립이 많음, 비매수 ≥1 비율 47.8%) → 6-1 질문 ②.

#### 변화 우선 (A-3, R5)

- **이벤트**: 의견 상향·하향(4단계 이동), 목표가 상향·하향(같은 증권사 직전 대비), 신규 커버(미국 `Action=init`만, 국내는 구분 불가). **커버 중단은 두 소스 모두 데이터로 구분되지 않는다.** 국내 등급 → `NotRated` 전환은 12개월에 2건뿐이고, `NotRated`가 있는 388쌍 중 329쌍은 처음부터 `NotRated`다. 그래서 커버 중단을 부정 신호로 쓰지 않는다.
- **데이터 형태**: KIS 직전 의견 필드는 표본 642건 전부 현재 의견과 같아 쓸 수 없다 → 연속 이력을 직접 비교한다. yfinance는 `Action`·`priceTargetAction`·`priorPriceTarget`가 실제 변화와 일치해 필드를 그대로 쓴다. 두 소스 모두 사실상 "바뀐 건 위주" 로그다(국내 연속 쌍 중 재확인 4.4%, 미국 7.7%, R6 1-2절).
- **창**: 90일. 비교 가능 3곳 이상 국내 157(30일은 102)·미국 262. 상대 신호 한 달 변동은 국내 15.9%·미국 13.9%로 가장 낮다.
- **절대 vs 상대**: 절대 건수("하향 ≥ 2 × 상향")는 시장 국면을 그대로 옮긴다. 국내 지금(2026-10 목표가 변경의 76.3%가 하향) 57.8% 종목이 "하향 우세", 미국 평온기 2018-01은 4.5%, 2022-06은 57.2%다. 상대 방식은 늘 약 10%다 → **상대 방식을 채택하고, 화면에 시장 전체 중앙값을 함께 적어** 일괄 하향은 사실로 보여 준다.
- **의견 변화는 신호로 쓰지 않는다**: 국내 90일 의견이 바뀐 종목은 27/340뿐이다. 사실 문구("90일 의견 하향 1곳")로만 보인다.
- **수준·변화 충돌**: 합치지 않고 두 줄로 보이며 변화 줄을 위에 둔다. 반대 방향 충돌은 국내 2종목(포스코퓨처엠·LG생활건강: 수준 부정 + 목표가 상향), 미국 5종목(BA·CRH·MTZ: 수준 긍정 + 하향 / MRNA·IT: 반대)뿐이다.
- **이력 없을 때**: KIS는 12개월, yfinance는 2011년부터 이력을 준다 → 첫 적재 직후부터 계산할 수 있다. 스냅샷을 기다릴 필요가 없다.

#### 근거 등급 (A-3-7)

논문 본문은 구독 벽(HTTP 403) 때문에 **미확인**이다. 초록(IDEAS/RePEc)과 다른 문헌의 요약으로 확인했다.

| 화면 요소 | 참고 연구 | 등급 | 이유 |
|---|---|---|---|
| 의견 상향·하향 사실 표시 | Womack(1996): 새 매수·매도 추천 뒤 표류 +2.4%/−9.1%(매도 쪽이 길고 큼). Jegadeesh 외(2004): 컨센서스 변화는 견고한 예측 변수. Barber·Lehavy·Trueman 원고: 수준·변화 모두 정보 | **B** | 연구는 추천 변경 뒤 포트폴리오 수익률을 봤다. 우리는 개수를 세기만 하고 수익률로 검증하지 않았다 |
| 목표가 변화 신호 | 김준석(2026, 자본시장연구원 26-06): 국내 목표가 변화도 유의한 초과수익. 하향은 상향보다 느리고 크다 | **B**(개념) · **C**(90일·10%·시장 상대·3곳은 자체 선택) | 요청서가 지정한 두 논문은 추천을 다뤘고 목표가는 다루지 않았다 |
| 수준 신호 | Jegadeesh 외: 수준은 통제 후 유의하지 않음. Barber 외: 유의 | **C** | 연구 간 결과가 엇갈리고, 국내는 매수 91%(26-06)라 정보가 더 약함 |
| 목표가 괴리율 | 26-06: 국내 목표가 내재 수익률 33.9% vs 실현 약 4% | **C**(설명용) | "상승 여력"으로 읽으면 안 된다는 근거 |

미국 결과를 국내에 그대로 쓸 수 없는 이유: ① 국내 의견 분포는 매수 91%, 이번 데이터의 종목별 매수 비율 중앙값은 1.0이다. ② 2013년 이후 국내 의견·목표가의 투자 가치가 관찰되지 않았다(26-05, 본문 미확인). ③ KIS 데이터에 외국계 증권사가 없다. ④ 미국 연구 표본은 1985~2006년이다. → 화면에는 사실만 적고 해석을 붙이지 않는다.

#### 최소 건수와 표시 문구 (A-4)

- 최소 3곳(수준·변화 공통). 2·3·5곳으로 바꿔도 신호 비율은 9.5~10%로 같고, 바뀌는 것은 "의견 적음" 종목 수다(국내 변화 통과 187/157/116). 정확히 3이어야 할 근거는 없다(**추측** 성분).
- 문구 초안(작은 회색 글씨, 방향어는 "하향 우세"/"상향 우세" 두 단어만, 색·아이콘으로 좋고 나쁨을 칠하지 않음):
  1. 변화(위 줄): `애널리스트 · 목표가 하향 우세 — 90일: 하향 12곳 · 상향 0곳 · 중앙값 −39% (시장 −9%) · 10/28 기준`
  2. 수준: `의견 · 6개월 증권사 17곳 중 매수 14 · 중립 3 — 매수 비중 시장 하위 10%` / 신호 없으면 `… 22곳 중 매수 22`
  3. 미달: `애널리스트 의견 적음 (6개월 2곳) · 10/28 기준`
  4. 일괄 조정 중(시장 중앙값 ≤ −5%, **추측** 임계): `최근 90일 시장 전체 목표가 중앙값 −9% (일괄 하향 구간)`
  5. 출처: 국내 `국내 증권사 25곳(KIS) 기준 · 외국계 제외`, 미국 `Yahoo Finance 기준`
