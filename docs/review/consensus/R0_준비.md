### 데모·과제 vs 공개 서비스

- **과제 발표·데모(비상업, 소수 사용자)**: yfinance는 이미 시세·재무 보완에 쓰고 있는 것과 같은 위험 수준이다. 화면에 출처("Yahoo Finance", "한국투자증권")를 표시한다. KIS는 개인 계좌 키로 받은 데이터를 데모 화면에 보여 주는 정도로 본다. 단, 약관 본문이 미확인이므로 확정하지 않는다.
- **공개 서비스(불특정 다수, 상업)**: Yahoo 약관 2(d)(9)·2(e)·2(h)에 정면으로 걸린다 → 유료 데이터 계약 없이는 불가. KIS도 "외부 고객에게 서비스 제공 = 법인 제휴 대상"이라 개인 키로는 불가로 본다.
- 이 차이는 R7 보고서의 제약·리스크 열과 6장 질문에 그대로 옮긴다.
